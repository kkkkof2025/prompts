## 三种阅读策略

### 🏃 极速体验（30 分钟）

```
AI 第一天 → Ch01 基本对话 → 选 3 个 Prompt 即用库模板试一遍
```

适合：想快速感受 AI 能做什么的人。

### 🚴 系统学习（2 周）

```
第 1 周：Ch00→Ch01→Ch02→Ch03→Ch04→Ch05 → 每天选 1 个 Prompt 练习
第 2 周：Ch06→Ch07→Ch08→Ch09→Ch13→Ch14 → 建 1 个 Skill + 1 个记忆文件
```

适合：想系统掌握 AI 使用方法的人。

### 🏊 深度实战（30 天 +）

```
按 [Ch14 30 天计划](chapters/14-practice-plan.md) 完整执行，加上：
- 第 15 天后：选一个 Capstone 项目（见[端到端实战指南](capstone-projects.md)）
- 第 22 天后：搭建自己的 agent（见 Ch08）
- 第 28 天后：写《我的 AI 30 天》总结文章
```

适合：想把 AI 变成核心工作能力的人。

## 怎么用这本书

1. **不要读完再用**：读完一章，马上用那一章的方法做一件事。
2. **跳着读没关系**：上面的角色路径是建议，不是规矩。
3. **速查页和完整章并用**：日常查 [速查讲义](quick-reference.md) 和 [Prompt 即用库](prompt-templates-library.md)，需要深入时再读完整章。
4. **遇到问题先看** [常见误区](common-pitfalls.md) 和 [Prompt 调试指南](prompt-debugging-guide.md)。
5. **打印出来当参考**：[速查讲义](quick-reference.md)、[检查清单](appendix-checklists.md)、[30 天跟踪表](30day-tracking-sheet.md) 都适合打印。
