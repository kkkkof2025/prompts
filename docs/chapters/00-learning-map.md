# 第 0 章：学习路线图

很多人学习 AI 的方式是从工具开始：今天试一个模型，明天看一个插件，后天收藏一堆 prompt。这样会很快，但也很乱。更稳定的路线是先建立能力层级，再选择工具。

## 四层能力

第一层是表达。你要能把“我想要什么”说清楚。AI 不怕任务复杂，怕的是目标模糊、上下文缺失、标准变化。

第二层是拆解。大任务通常不能一次交给模型。你需要把任务拆成理解、计划、执行、检查、改写几个阶段。

第三层是复用。常见任务不应该每次从头写 prompt。你可以把成熟流程沉淀为模板、checklist、skill、脚本或 agent 工作流。

第四层是判断。AI 会出错，会编造，会误解边界，也可能调用错误工具。越强的 AI 越需要清晰验收和审计。

## 推荐学习顺序

1. 学会基础对话：目标、背景、角色、约束、输出格式。
2. 学会 prompt：任务拆解、示例、反例、评估标准。
3. 学会验证：交叉检查、引用来源、运行测试、让模型解释不确定性。
4. 学会工具：文件、搜索、代码、数据库、浏览器、自动化平台。
5. 学会知识库：把你的资料变成可检索上下文。
6. 学会 skills：把固定流程变成可复用能力包。
7. 学会 agent：让 AI 在边界内计划、行动、观察、修正。
8. 学会治理：权限、隐私、成本、安全和责任。

## 不同人群怎么学

学生和自学者：先用 AI 做解释、练习题、错题分析和学习计划，但每次都要让 AI 给出处、例子和检查题。

职场用户：从邮件、总结、会议纪要、研究、表格分析开始，把高频工作做成模板。

产品和运营：重点学习用户需求分析、竞品分析、实验设计、文案版本和数据解释。

工程师：重点学习代码阅读、测试生成、重构计划、故障定位、工具调用和 agent 边界。

管理者：重点学习组织知识库、AI 使用规范、数据安全、流程审计和能力评估。

## 一个最小实践循环

每次使用 AI，都可以走这个循环：

```text
目标 -> 背景 -> 约束 -> 让 AI 提问 -> 执行 -> 验收 -> 记录可复用经验
```

示例：

```text
目标：帮我制定 7 天 Python 入门计划。
背景：我会 Excel，不会编程，每天 1 小时。
约束：不要安排安装复杂环境，优先使用浏览器可运行工具。
提问：如果信息不够，请先问我最多 3 个问题。
输出：用表格列出每天目标、练习、验收标准。
```

## 你应该避免的学习方式

不要只收藏 prompt。收藏没有错，但不理解为什么有效，就无法迁移。

不要把 AI 当搜索引擎。AI 适合整理、推理、生成和协作；事实核验仍需要来源。

不要一开始就做复杂 agent。agent 的风险来自它能行动。没有边界、测试和审计，自动化越强，错误越大。

不要迷信模型排名。排行榜能提供参考，但你的任务、数据、成本、延迟和隐私要求更重要。

## 本书怎么用

每章建议至少做一个练习。你不需要一次读完。真正有效的学习方式是：读一小节，立刻把模板用到自己的任务上，记录哪里有效、哪里失败，然后改进。

当你发现某个 prompt 或流程反复好用，就把它保存到 `examples/` 或自己的知识库中。AI 学习的核心不是“知道更多名词”，而是让自己的工作系统持续变聪明。
