# 第 1 章：从最基本的对话开始

AI 对话的本质不是“问一句，答一句”，而是把你的意图转成模型能理解和执行的任务。大多数效果差的对话，不是模型完全不行，而是任务没有被说清楚。

## 本章导读

- 预计阅读时间：12-18 分钟。
- 学习目标：掌握目标、背景、约束、标准和输出格式五要素；学会让 AI 先提问；用追问修正一次不稳定回答。
- 练习入口：[章节练习与验收映射表](../chapter-validation-map.md) 和 [课堂练习工作纸](../classroom-worksheets.md)。
- 相关材料：[Prompt 模式实践模板](../../examples/prompt-patterns.md) 和 [真实应用案例](../case-studies.md)。

## 一个好问题的五个部分

一个稳定的问题通常包含：

- 目标：你要 AI 做什么。
- 背景：它需要知道什么上下文。
- 约束：哪些不能做，哪些必须做。
- 标准：怎样才算完成。
- 输出：你希望它用什么格式回答。

差问题：

```text
帮我写个学习计划。
```

好问题：

```text
请帮我制定一个 14 天 AI 入门学习计划。
背景：我每天晚上有 45 分钟，主要想提高工作中的写作和资料整理效率。
约束：不要安排编程内容；每天必须有一个能立刻完成的小练习。
标准：计划要由浅入深，不能只列工具名。
输出：用表格给出每天主题、学习内容、练习、验收方式。
```

## 让 AI 先提问

当你不确定自己有没有说清楚，可以让 AI 先问问题。

```text
我想让你帮我做一个方案。在开始之前，请先判断信息是否足够。
如果不够，请只问我最多 3 个最关键的问题，不要直接开始写。
```

这个习惯很重要。它把“猜测式回答”变成“澄清后回答”。

## 角色不是魔法

很多 prompt 会写“你是一位世界顶级专家”。角色设定有用，但它不是魔法。真正有用的是角色带来的判断标准。

低效写法：

```text
你是顶级营销专家，帮我写文案。
```

更好的写法：

```text
请以 B2B SaaS 产品营销负责人的视角，帮我改写下面这段落地页文案。
判断标准：
1. 让首次访问者在 10 秒内理解产品解决什么问题。
2. 减少夸张形容词。
3. 保留可验证的价值主张。
```

## 输出格式能减少返工

如果你要表格，就直接说表格。如果你要 JSON、Markdown、清单、邮件、会议纪要，也要直接说。

```text
输出格式：
- 先给 5 条结论。
- 每条结论后面给证据或理由。
- 最后给一个“我还需要核验的信息”列表。
```

格式不是装饰。格式决定了你能否快速阅读、复制、比较和继续加工。

## 控制长度和深度

AI 容易回答太宽。你可以明确控制范围。

```text
请用 300 字以内解释给初学者。
不要展开历史背景。
只讲最关键的 3 个概念，并各给一个生活例子。
```

或者：

```text
请用专家级深度分析。
先列出结论，再列推理链条、反例、边界条件和可能出错的地方。
```

## 追问比首问更重要

优秀对话通常不是一次完成，而是多轮迭代：

1. 先让 AI 给初稿。
2. 让 AI 自查问题。
3. 你指出不符合需求的地方。
4. 让 AI 基于反馈重写。
5. 保存最终可复用模板。

可用追问：

```text
请从准确性、完整性、可执行性三个角度检查你刚才的回答。
不要重写全文，只列出最需要修改的 5 个点。
```

```text
请保留原来的结构，但把第 2 部分改得更适合完全没有背景的读者。
```

## 手把手实战演练：从一团糟到完美交付

下面用一个真实场景带你走通完整的"失败→分析→修正→验收"循环。

### 场景设定

你是一家电商公司的运营，老板让你写一份"618大促活动复盘报告"。你打开 AI，写下了第一版提示词。

### 第1轮：第一版提示词（典型新手写法）

你写的 prompt：

```text
帮我写一份618大促活动的复盘报告。
```

AI 的回复（典型"说了等于没说"的回答）：

```
618大促活动复盘报告

一、活动概述
本次618大促活动已圆满结束，整体表现良好。

二、销售数据
活动期间销售额有明显增长，多个品类表现突出。

三、流量分析
各渠道流量均有提升，其中部分渠道表现尤为亮眼。

四、问题与改进
活动整体顺利，但仍有优化空间。

五、总结
建议继续保持现有策略，同时关注新兴渠道机会。
```

### 🤔 问题分析

我们来诊断一下这份回复为什么不行：

| 问题 | 具体表现 | 根本原因 |
|------|---------|---------|
| **空洞无物** | "表现良好""有明显增长"——没有任何数据 | 你没告诉AI你有什么数据 |
| **没有结构** | 标题随意，没有具体指标 | 你没要求输出格式 |
| **不可用** | 这份报告发给老板会被问"所以呢？" | 你没说明报告用途和验收标准 |
| **AI在编造** | AI不知道你的真实数据，只能泛泛而谈 | 你没提供具体数据和背景 |

**核心问题**：你把 AI 当成"猜心大师"，而不是"需要工作说明书的执行者"。

### 第2轮：用五要素重写

现在用第1章学到的五要素框架，重新写这个 prompt：

```text
目标：
帮我写一份618大促活动的复盘报告，总结得失，给出可执行的改进建议。

背景：
我是电商运营，公司主营家居日用品。以下是我们本次618的真实数据：
- 总GMV：580万（目标500万，完成116%）
- 客单价：186元（日常为142元，提升31%）
- 订单量：31,183单
- 退货率：8.2%（日常5.1%）
- 主要流量来源：抖音直播42%，淘宝搜索28%，私域社群18%，其他12%
- 爆品TOP3：收纳盒套装（9600单）、厨房清洁套装（7800单）、浴室置物架（5200单）
- 主要投诉：发货延迟（占投诉的45%）、包装破损（28%）、尺寸不符（15%）

约束：
- 不要编造我未提供的数据
- 语气专业但不死板，适合内部汇报
- 批评和建议要有建设性，不要只说"不好"

标准：
- 能直接用在团队周会上汇报（不需要我大改）
- 每项分析都要有"数据→解读→建议"的逻辑链

输出格式：
1. 核心结论（3条，每条不超过40字）
2. GMV与目标达成分析
3. 爆品分析：为什么爆？下一场大促怎么复制？
4. 退货率上升原因分析与对策
5. 投诉问题处理与供应链改进
6. 下次大促的3个具体改进行动
```

AI 的回复（显著改善）：

```
618大促活动复盘报告

1. 核心结论
- 超额完成目标，GMV达成116%，客单价提升31%是核心驱动力
- 爆品集中度高，TOP3占订单量72%，中小品曝光不足
- 退货率升至8.2%需优先解决，发货延迟和包装问题是根因

2. GMV与目标达成分析
| 指标 | 目标值 | 实际值 | 达成率 |
|------|--------|--------|--------|
| GMV | 500万 | 580万 | 116% |
| 客单价 | - | 186元 | 较日常+31% |
| 订单量 | - | 31,183单 | - |

**解读**：客单价提升是超目标的主要驱动力。收纳套装（客单229元）和厨房清洁套装（客单198元）的高客单价拉高了整体水平。

**建议**：下次大促延续"高客单爆品+满减凑单"策略。

3. 爆品分析
...（后续内容理性分析、数据驱动、建议可执行）
```

### 🤔 效果对比

| 维度 | 第一版 | 第二版 | 差异原因 |
|------|--------|--------|---------|
| 可用性 | ❌ 完全不能用 | ✅ 可直接汇报 | 有了真实数据 |
| 深度 | ❌ 空话套话 | ✅ 数据驱动分析 | 指定了"数据→解读→建议"逻辑链 |
| 结构 | ❌ 随意 | ✅ 清晰分层 | 明确了输出格式 |
| 风险 | ❌ AI在编造 | ✅ 限定了我提供的数据 | 有约束条件 |

### 第3轮：追问深化（让好变得更好）

第二版已经不错了，但你可以用追问让它更好：

```text
请基于刚才的报告，帮我做3件事：

1. 把"退货率上升"这段改成给供应链团队看的版本，
   增加具体责任分工建议和预估改进周期。

2. 检查报告中是否有逻辑矛盾或数据跳跃的地方。
   只列问题，不重写全文。

3. 给我3个"下次大促前的checklist要点"，
   每个要点要能在5分钟内判断是否准备就绪。
```

如果你想保存这个好用的 prompt 模板以便下次复用，可以这样整理：

```text
# 模板：大促活动复盘报告
触发场景：每次大促结束后24小时内
输入要求：销售数据、流量来源、爆品清单、投诉分类
输出：6部分标准复盘报告
```

保存到 `templates/` 文件夹里，下次直接调用，不再从零开始。

### 🎯 这段实战教会你什么

1. **AI 不是猜心大师**——你不给数据，它就瞎编。
2. **"帮我写" vs "帮我分析"的区别是天壤之别**——前者给模板，后者给分析。
3. **好的 prompt 是一次投资**——花 10 分钟写好，省下 30 分钟返工。
4. **追问比首问更重要**——永远留一轮"自查+修改"。
5. **及时存档**——好用的 prompt 存成模板，不要每次从头写。

## 练习

找一个你最近真实要完成的任务。不要直接让 AI 做，而是先写出五个部分：

```text
目标：
背景：
约束：
标准：
输出格式：
```

然后再加一句：

```text
如果信息不足，请先问我最多 3 个问题。
```

你会发现，AI 的质量提升通常来自你把任务讲得更像“工作说明书”，而不是更像“愿望”。
