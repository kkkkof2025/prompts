# 第 1 章：从最基本的对话开始

AI 对话的本质不是“问一句，答一句”，而是把你的意图转成模型能理解和执行的任务。大多数效果差的对话，不是模型完全不行，而是任务没有被说清楚。

## 本章导读

- 预计阅读时间：12-18 分钟。
- 学习目标：掌握目标、背景、约束、标准和输出格式五要素；学会让 AI 先提问；用追问修正一次不稳定回答。
- 练习入口：[章节练习与验收映射表](../chapter-validation-map.md) 和 [课堂练习工作纸](../classroom-worksheets.md)。
- 相关材料：[Prompt 模式实践模板](../../examples/prompt-patterns.md) 和 [真实应用案例](../case-studies.md)。

## 一个好问题的五个部分

一个稳定的问题通常包含：

- 目标：你要 AI 做什么。
- 背景：它需要知道什么上下文。
- 约束：哪些不能做，哪些必须做。
- 标准：怎样才算完成。
- 输出：你希望它用什么格式回答。

差问题：

```text
帮我写个学习计划。
```

好问题：

```text
请帮我制定一个 14 天 AI 入门学习计划。
背景：我每天晚上有 45 分钟，主要想提高工作中的写作和资料整理效率。
约束：不要安排编程内容；每天必须有一个能立刻完成的小练习。
标准：计划要由浅入深，不能只列工具名。
输出：用表格给出每天主题、学习内容、练习、验收方式。
```

## 让 AI 先提问

当你不确定自己有没有说清楚，可以让 AI 先问问题。

```text
我想让你帮我做一个方案。在开始之前，请先判断信息是否足够。
如果不够，请只问我最多 3 个最关键的问题，不要直接开始写。
```

这个习惯很重要。它把“猜测式回答”变成“澄清后回答”。

## 角色不是魔法

很多 prompt 会写“你是一位世界顶级专家”。角色设定有用，但它不是魔法。真正有用的是角色带来的判断标准。

低效写法：

```text
你是顶级营销专家，帮我写文案。
```

更好的写法：

```text
请以 B2B SaaS 产品营销负责人的视角，帮我改写下面这段落地页文案。
判断标准：
1. 让首次访问者在 10 秒内理解产品解决什么问题。
2. 减少夸张形容词。
3. 保留可验证的价值主张。
```

## 输出格式能减少返工

如果你要表格，就直接说表格。如果你要 JSON、Markdown、清单、邮件、会议纪要，也要直接说。

```text
输出格式：
- 先给 5 条结论。
- 每条结论后面给证据或理由。
- 最后给一个“我还需要核验的信息”列表。
```

格式不是装饰。格式决定了你能否快速阅读、复制、比较和继续加工。

## 控制长度和深度

AI 容易回答太宽。你可以明确控制范围。

```text
请用 300 字以内解释给初学者。
不要展开历史背景。
只讲最关键的 3 个概念，并各给一个生活例子。
```

或者：

```text
请用专家级深度分析。
先列出结论，再列推理链条、反例、边界条件和可能出错的地方。
```

## 追问比首问更重要

优秀对话通常不是一次完成，而是多轮迭代：

1. 先让 AI 给初稿。
2. 让 AI 自查问题。
3. 你指出不符合需求的地方。
4. 让 AI 基于反馈重写。
5. 保存最终可复用模板。

可用追问：

```text
请从准确性、完整性、可执行性三个角度检查你刚才的回答。
不要重写全文，只列出最需要修改的 5 个点。
```

```text
请保留原来的结构，但把第 2 部分改得更适合完全没有背景的读者。
```

## 练习

找一个你最近真实要完成的任务。不要直接让 AI 做，而是先写出五个部分：

```text
目标：
背景：
约束：
标准：
输出格式：
```

然后再加一句：

```text
如果信息不足，请先问我最多 3 个问题。
```

你会发现，AI 的质量提升通常来自你把任务讲得更像“工作说明书”，而不是更像“愿望”。
