> AI 领域变化极快。没有人能"学完"AI。持续学习的能力比任何单个技能都重要。这一节帮你建立自己的持续学习系统。

### 1.2 建立信息过滤系统

不要试图读完所有 AI 资讯。建立一个三层过滤：

```text
第1层（每日5分钟）：扫 TLDR AI / 即刻热榜，只看标题
      ↓ 真正感兴趣的（约10%）
第2层（每周30分钟）：精读 2-3 篇深度文章
      ↓ 和你的工作/学习相关的
第3层（每月2小时）：动手试一次（跑demo、复现案例、写笔记）
```

## 二、参与开源项目

### 2.1 入门路径

**新手友好项目**（适合第一次贡献）：

| 项目 | 可以贡献什么 | 入门难度 |
|------|------------|---------|
| OpenClaw | 写文档、翻译、写 Skill 样例 | ⭐ |
| 各 AI 框架的文档翻译 | 中译英 / 英译中 | ⭐ |
| 开源 prompt 合集 | 提交好用的 prompt | ⭐ |
| AI Cookbook 项目 | 提交使用案例和教程 | ⭐⭐ |

### 2.2 如何提交你的第一个 PR

```text
1. Fork 仓库 → 2. Clone 到本地 → 3. 建分支 →
4. 修改 → 5. Commit → 6. Push → 7. 创建 Pull Request
```

**第一步建议**：找一个有 "good first issue" 标签的 issue，从修文档错别字或翻译开始。

### 2.3 贡献指南

1. **先读 CONTRIBUTING.md**：每个项目都有贡献规范
2. **从小做起**：第一个 PR 保持 10 行以内
3. **描述清楚**：PR 标题和描述要说明"改了什么、为什么"
4. **接受反馈**：维护者的 review 是学习机会，不是批评
5. **保持礼貌**：开源社区靠善意运转

## 三、建立个人品牌

学习 AI 不只是"输入"，"输出"同样重要。教别人是最好的学习方式。

### 3.1 平台选择

| 平台 | 内容类型 | 优势 | 适合 |
|------|---------|------|------|
| 知乎 | 长文章 | AI话题流量大、搜索引擎收录好 | 深度技术文章 |
| 掘金 | 技术文章 | 开发者社区、氛围好 | 工程/代码类 |
| 微信公众号 | 图文 | 私域、复利效应 | 建立个人IP |
| B站/YouTube | 视频教程 | 视觉化教学 | 教程类 |
| 即刻/𝕏(Twitter) | 短内容 | 快速积累影响力 | 资讯+观点 |
| GitHub | 代码/文档 | 直接展示工程能力 | 作品集 |

### 3.2 起步策略

**不要一上来就想写"爆款"**。前 3 个月的目标是：

| 月份 | 目标 | 行动 |
|------|------|------|
| 第1月 | 养成输出习惯 | 每周1篇，不限字数，不限质量 |
| 第2月 | 找到擅长方向 | 根据阅读量/反馈调整内容方向 |
| 第3月 | 建立最小读者群 | 和 10 个读者建立互动关系 |

### 3.3 选题建议

**最容易起步的 5 个选题方向**：

1. **"我用 AI 做了 X"**：记录真实使用过程，附上 prompt 和效果
2. **"X 工具的 N 个实用技巧"**：整理你的使用心得
3. **"AI 帮我省下了 Y 小时"**：量化效果，讲流程改进
4. **"比较 A 和 B，我选了 C"**：对比评测，展示决策思维
5. **"踩坑记录：我用 AI 做 X 时犯的 N 个错误"**：失败经验最有价值

### 3.4 内容质量标准

一篇好的 AI 技术文章应该：

- [ ] 有具体可复现的 prompt / 代码
- [ ] 有效果对比（before/after）
- [ ] 有失败经历和教训
- [ ] 不说"AI太强了"这类空话
- [ ] 对读者有可操作的下一步建议

## 五、持续学习路线图

### 5.1 月度节奏

```text
第1周：学一个新概念或工具
第2周：在真实任务中应用
第3周：记录经验，公开发布
第4周：复盘 + 更新知识库和 skill
```

### 5.2 季度复盘清单

每季度末回答以下问题：

```text
1. 这季度我学到的 3 个最重要的概念是什么？
2. 我创建/更新了几个 skill？哪些还在用，哪些废弃了？
3. 我的 AI 使用效率提升了多少？（量化：时间/质量）
4. 我公开发布了几篇内容？收到什么反馈？
5. 下季度我最应该深耕哪个方向？
6. 哪些之前认为重要的东西现在看来不那么重要了？
```

### 5.3 年度目标建议

| 经验水平 | 年度目标 |
|---------|---------|
| 初学者（第1年） | 建立稳定 AI 使用习惯，完成 2 个实战项目 |
| 有经验者（第2年） | 深耕 1 个方向，对外输出 12+ 篇文章，贡献开源 |
| 进阶者（第3年+） | 成为某个细分方向的专家，开始帮别人学习 |

## 六、常见陷阱与建议

### ❌ 不要做的事

1. **追每个新工具**：底层原理相通，吃透3个比知道30个强
2. **只学不用**：没有真实任务驱动，一个月后全忘
3. **闭门造车**：不输出、不交流、不分享
4. **焦虑学习**：看到别人用 AI 做了X就觉得自己落后了
5. **追求完美**：第一篇文章永远可以更好，先发出去

### ✅ 应该做的事

1. **用真实任务驱动学习**：永远有一个"需要AI解决的真实问题"
2. **建立知识库**：把学到的内容存成可检索的文档
3. **定期复盘**：每周/每月回头看，删掉不用的，优化还用得到的
4. **教别人**：写文章、做分享、回答社区问题
5. **保持好奇心但不焦虑**：AI领域永远有新东西，你不需要全部知道
