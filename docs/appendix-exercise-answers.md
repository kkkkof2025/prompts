# 附录 C：练习参考答案

这里提供的是参考答案，不是唯一答案。学习 AI 最重要的是把模板迁移到自己的真实任务里。

## 第 1 章练习：五要素 Prompt

题目：找一个真实任务，写出目标、背景、约束、标准、输出格式。

参考答案：

```text
目标：
请帮我整理一份 10 分钟内部分享稿，主题是“普通职场人如何用 AI 提高资料整理效率”。

背景：
听众是行政、运营和市场同事，大多会用 AI 聊天，但没有系统方法。

约束：
不要讲模型训练原理，不要使用编程示例。内容必须能在免费或常见 AI 工具中实践。

标准：
听众听完后能立刻用一个模板整理文章或会议纪要。

输出格式：
先给分享结构，再给逐段讲稿，最后给一个可复制 prompt。

如果信息不足，请先问我最多 3 个问题。
```

## 第 3 章练习：弱 Prompt 改写

原 prompt：

```text
帮我做一个 AI 学习计划。
```

参考改写：

```text
请为我制定一个 4 周 AI 学习计划。

我的背景：
- 我是产品经理，不会编程。
- 每周可以投入 4 小时。
- 主要目标是用 AI 提高调研、需求分析和文档写作效率。

约束：
- 不安排数学和模型训练内容。
- 每周必须有一个可提交的小成果。
- 优先使用网页端 AI 工具。

输出格式：
用表格列出每周主题、学习内容、练习任务、小成果和验收标准。

验收标准：
计划必须由浅入深，并且每个练习都能在 1 小时内完成。
```

## 第 4 章练习：5 步工作流

任务：每周写工作周报。

参考答案：

```text
工作流名称：周报生成

第 1 步：收集材料
输入：本周任务列表、会议纪要、完成事项、未完成事项。
输出：原始事实列表。

第 2 步：分类整理
输入：原始事实列表。
输出：已完成、进行中、风险、下周计划四类内容。

第 3 步：提炼成果
输入：已完成事项。
输出：每项工作的结果、影响和可量化指标。

第 4 步：生成周报
输入：分类内容和成果。
输出：适合发给直属上级的周报。

第 5 步：自检
输入：周报草稿。
输出：缺少数据、表达夸张、责任不清、下周计划不具体的问题清单。
```

## 第 5 章练习：小型评测集

任务：比较两个客户反馈分类 prompt。

参考评测集：

| 输入 | 期望分类 |
| --- | --- |
| 后台今天一直打不开，提示 502 | 故障反馈 |
| 功能挺好，但价格对小团队太贵了 | 价格异议 + 正面评价 |
| 能不能支持飞书审批流 | 功能需求 |
| 客服回复太慢，昨天的问题还没解决 | 服务体验 |
| 使用三个月了，整体稳定，续费可以谈吗 | 续费意向 |

评分表：

```text
分类准确性：1-5
是否允许多标签：1-5
是否解释原因：1-5
是否标注不确定样例：1-5
格式是否稳定：1-5
```

## 第 7 章练习：最小 Skill

参考答案：

```markdown
# 周报整理 Skill

## 一句话用途
把零散工作记录整理成可发给上级的周报。

## 输入
- 本周完成事项。
- 未完成事项。
- 重要会议或决策。
- 下周计划。

## 输出
1. 本周重点成果
2. 进行中事项
3. 风险和需要支持
4. 下周计划

## 边界
不编造数据、不替用户承诺截止时间、不夸大成果。

## 验收标准
- 每条成果有具体动作或结果。
- 风险写清影响和需要谁支持。
- 下周计划可执行。
```

## 第 8 章练习：Agent 工作说明

参考答案：

```text
目标：
请帮我检查 docs/ 目录中的 Markdown 链接是否有效，并列出失效链接。

可使用工具：
- 读取 Markdown 文件。
- 运行本地只读检查命令。

禁止事项：
- 不修改文件。
- 不联网替换链接。
- 不删除任何内容。

验收标准：
- 列出检查过的文件数量。
- 列出所有失效链接及所在文件。
- 如果没有失效链接，明确说明。

需要人工确认的动作：
- 修复或替换链接。
- 删除任何引用。
```

## 第 10 章练习：个人助手说明书

参考答案：

```text
助手名称：
学习项目助手

主要用途：
帮助我整理 AI 学习资料、维护书稿进度、生成练习任务。

每天固定任务：
总结我新增的资料，更新待办，提示需要核验的信息。

允许读取的资料：
当前项目的 README、MEMORY、docs 和 examples。

允许写入的位置：
只写入我指定的草稿文件。

禁止动作：
不删除文件，不访问密钥，不自动发布到 GitHub。

需要记住的信息：
书稿目标、章节结构、写作风格偏好。

需要定期遗忘的信息：
临时任务路径、一次性测试内容、已经过期的工具信息。
```

## 第 12 章练习：行业影响分析

示例：教育行业。

```text
AI 已经能改变的 3 件事：
1. 个性化解释和练习生成。
2. 教师备课、题目改写和资料摘要。
3. 学生作文、语言学习和错题分析。

未来 1-2 年可能改变的 3 件事：
1. 多模态作业反馈。
2. 面向班级的学习数据分析。
3. 与校内知识库结合的教学助手。

最可能被夸大的 3 件事：
1. 完全替代教师。
2. 自动判断所有学生真实能力。
3. 不需要人工设计课程。

最大风险：
学生过度依赖、隐私泄露、错误反馈、评价不公平。

我应该学习的能力：
设计高质量练习、核验 AI 输出、保护学生数据、建立课堂使用规范。
```

## 第 13 章练习：个人 AI 安全规范

参考答案：

```text
我允许 AI 处理的数据：
公开资料、自己写的草稿、非敏感学习笔记。

我禁止上传的数据：
密码、密钥、身份证、银行卡、客户资料、公司未公开代码。

需要人工复核的任务：
事实引用、法律医疗金融建议、对外发布内容、重要邮件。

需要引用来源的任务：
新闻、论文、法规、价格、模型能力、产品参数。

允许自动执行的动作：
整理草稿、生成清单、检查格式、提出修改建议。

永远不能自动执行的动作：
付款、删除文件、发布内容、发送重要邮件、修改权限。
```
