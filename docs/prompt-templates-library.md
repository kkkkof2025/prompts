# AI Prompt 即用库

> 30 个即抄即用的 prompt 模板。找到你要的任务，复制→填入你的信息→发给 AI。

---

## 写作类

### 1. 写邮件

```text
帮我写一封邮件回复客户。

收件人是 [角色]，他想了解 [话题]。
我需要告诉他：[核心信息1]、[核心信息2]。
语气：[专业友好/正式/轻松]。
长度：150 字以内。

如果我说得不清楚，请先问我最多 2 个问题再写。
```

### 2. 写周报

```text
你是我的周报助手。请根据我提供的本周事项生成结构化周报。

本周完成：
- [事项A]
- [事项B]

进行中：
- [事项C]

遇到的阻塞：
- [阻塞D—写明原因和影响]

下周计划：
- [计划E]

格式要求：
- Markdown 标题：「本周工作周报 ({日期范围})」
- 每条不超过 2 行
- 阻塞事项必须标注影响范围
- 需要支持的事项放在最后

不要编造我没提到的内容。
```

### 3. 优化简历

```text
帮我优化下面这段简历描述。要求：
- 突出成果，不是职责
- 有具体数字（没有就标注“待补充”）
- 每条不超过 30 字
- 用动词开头

原文：
[粘贴你的简历描述]

优化后请列出每条改了哪里、为什么改。
```

### 4. 写产品介绍

```text
帮我写一段产品介绍。目标读者：[目标用户画像]。

产品名称：[名称]
核心功能：[1-2个最核心的功能]
与竞品的差异：[1-2个最突出的差异点]

要求：
- 150-200 字
- 让读者 10 秒内理解“这是什么、为什么需要它”
- 不用夸张营销词
```

### 5. 改写润色

```text
请帮我改写下面这段话。

原文：
[粘贴原文]

改写要求：
- 更适合 [目标读者] 阅读
- 保持原意不变
- 长度控制在 [X] 字以内
- 使用 [正式/口语/专业/通俗] 风格

改写后请说明做了什么改动。
```

## 编程类

### 6. 解释代码

```text
请帮我解释下面这段代码。

[粘贴代码]

请按以下结构回答：
1. 这段代码是做什么的（一句话）
2. 关键部分逐段解释
3. 有没有潜在问题（性能/安全/兼容性）
4. 如果有改进建议，请说明理由
```

### 7. 写代码

```text
请帮我写一段代码完成以下任务：

任务：[描述你要做什么]

语言/框架：[Python/JavaScript/Go/其他]
输入：[输入是什么格式]
输出：[期望的输出格式]
约束：
- [约束1，如“不依赖第三方库”]
- [约束2，如“时间复杂度不超过 O(n log n)”]

先解释思路，再写代码。代码中加上关键注释。
```

### 8. 调试 Bug

```text
我的代码出现了以下错误：

代码：
[粘贴相关代码]

错误信息：
[粘贴错误日志]

我已经尝试过：
[列出你试过但无效的方法]

请帮我：
1. 分析最可能的原因
2. 给出修复方案
3. 解释为什么会出这个错（帮助我下次避免）
```

### 9. 代码审查

```text
请帮我审查下面这段代码。

[粘贴代码]

请从以下角度检查：
1. 逻辑是否正确
2. 是否有安全风险（注入/越权/敏感信息泄露）
3. 是否有性能瓶颈
4. 命名和注释是否清晰
5. 是否有可以简化的部分

按优先级列出问题（严重 > 建议）。
```

### 10. 写测试用例

```text
请为下面这段函数写测试用例。

函数代码：
[粘贴代码]

要求：
1. 覆盖正常输入、边界值、异常输入
2. 用 [pytest/jest/go test] 格式
3. 每个测试用例说明测试意图
```

## 分析类

### 11. 总结文章

```text
请总结下面这篇文章。

[粘贴文章或链接内容]

要求：
- 3 句话总结核心观点
- 列出 3 个关键论据
- 指出文章中可能存在的逻辑缺陷或信息缺口
- 区分文章的“事实”和“观点”
```

### 12. 竞品分析

```text
请帮我分析两个产品的差异。

产品 A：[名称/链接/描述]
产品 B：[名称/链接/描述]

要求：
- 用对比表列出核心差异（功能/定价/目标用户/优劣势）
- 给出选择建议（什么情况下选 A，什么情况下选 B）
- 标注你不确定、需要我补充核验的信息
```

### 13. 数据分析

```text
请帮我分析以下数据。

数据：
[粘贴数据]

请回答：
1. 数据中最明显的趋势或规律是什么
2. 有没有异常值或值得注意的点
3. 如果我是 [你的角色，如产品经理]，我应该关注什么
4. 还需要什么额外数据来让分析更可靠

不要编造数据中不存在的结论。
```

### 14. 决策辅助

```text
请帮我分析这个决策。

背景：
[当前情况]

选项：
A. [选项A描述]
B. [选项B描述]
C. [选项C描述]

评估维度：
- 成本
- 时间
- 风险
- 长期影响

请按每个维度比较各选项，给出推荐并说明理由。
如果你的分析缺少关键信息，请先提问。
```

### 15. 文档审查

```text
请帮我审查下面这份文档。

[粘贴文档内容]

检查项：
1. 逻辑是否自洽
2. 是否有遗漏的重要信息
3. 数据和结论是否有来源支撑
4. 对目标读者（[读者画像]）是否清晰易懂
5. 是否有歧义或需要澄清的地方

按严重程度列出问题和建议。
```

## 学习类

### 16. 概念解释

```text
请用费曼学习法解释 [概念名称]。

要求：
1. 用一句话定义
2. 用生活中的类比解释（越简单越好）
3. 举一个正面例子和一个反面例子
4. 列出常见的 3 个误解
```

### 17. 学习计划

```text
我想在 [时间周期] 内学习 [技能/领域]。

我的背景：
- 已有基础：[相关经验]
- 每天可用时间：[X 小时]
- 学习目标：[具体目标，如“能独立完成XX”]

请帮我制定一个学习计划：
1. 分阶段目标（每周）
2. 每周具体任务
3. 推荐学习资源（免费优先）
4. 阶段性的检查点（我怎么判断自己学会了）
```

### 18. 论文精读

```text
请帮我精读下面这篇论文。

[粘贴论文摘要或关键段落]

请按以下结构回答：
1. 研究问题是什么（一句话）
2. 核心方法是什么（通俗解释）
3. 关键发现是什么
4. 有什么局限性或未解决的问题
5. 对我的 [你的领域] 工作有什么启发
```

### 19. 出题练习

```text
我在学习 [科目/技能]，请帮我出几道练习题。

难度：[入门/中级/挑战]
题型：[选择题/简答/实践题]
数量：[X] 道

要求：
- 每道题有明确考察点
- 提供答案和解析
- 答案放在最后，方便我先自己思考
```

### 20. 对比学习

```text
请帮我对比 [概念A] 和 [概念B]。

要求：
1. 用表格列出 5 个以上维度的对比
2. 举例说明什么时候用 A、什么时候用 B
3. 说明两者的关系（对立/互补/包含/递进）
```

## 工作类

### 21. 会议纪要

```text
请帮我把下面的会议内容整理成纪要。

原始内容：
[粘贴会议录音转录/聊天记录/笔记]

格式：
- 会议主题
- 关键决定（按重要性排序）
- 待办事项（责任人+截止时间）
- 风险和争议
- 待确认问题

没有的信息标注“待确认”，不要编造。
```

### 22. PPT 大纲

```text
请帮我生成一份 PPT 大纲。

主题：[主题]
听众：[听众画像]
时长：[X] 分钟
页数：[X] 页以内

要求：
- 每页标题 + 3 个要点
- 第一页是“为什么你应该关心这个”
- 最后一页是“现在你可以做的 3 件事”
- 推荐每页用什么类型的配图
```

### 23. 面试准备

```text
我要面试 [职位名称]，请帮我准备。

岗位描述：
[粘贴 JD]

我的背景：
[简述你的经验]

请帮我：
1. 分析这个岗位最看重哪 3 个能力
2. 列出 5 个可能问到的问题+回答思路
3. 指出我简历中最需要强调的经验
4. 给我 3 个反问面试官的好问题
```

### 24. 用户反馈分析

```text
请帮我分析下面这些用户反馈。

[粘贴多条用户反馈]

要求：
1. 按主题分类（如性能/UI/功能缺失/定价）
2. 统计每个类别的数量和严重程度
3. 指出最紧急需要处理的 3 个问题
4. 区分“可以快速修”和“需要大改”的问题
```

### 25. SOP/流程文档

```text
请帮我为 [任务/流程] 写一份标准操作流程(SOP)。

背景：[什么时候会用到这个流程，由谁执行]

要求：
1. 步骤清晰，每步有输入和输出
2. 标注检查点和常见错误
3. 新手能照着做，不需要额外解释
4. 控制在 [X] 步以内
```

## 创作类

### 26. 头脑风暴

```text
请帮我围绕 [主题] 做一次头脑风暴。

规则：
- 先量后质：先列出 20 个想法，不要评判
- 鼓励跨界：可以从其他行业借鉴灵感
- 不设限制：先不考虑可行性

分两轮：
第 1 轮：快速列出 20 个想法（每个不超过 10 字）
第 2 轮：从 20 个中选 5 个最有潜力的，展开成 100 字概要
```

### 27. 内容策划

```text
请帮我策划一个 [平台/媒介] 上的内容系列。

主题：[主题]
目标受众：[受众画像]
频率：[每周X篇]
时长：[每篇X分钟/字]

请给出：
1. 系列定位（一句话说清这个系列对受众的价值）
2. 前 10 期的选题列表（标题+一句话内容描述）
3. 每期的固定结构模板
```

### 28. 对话/脚本

```text
请帮我写一段 [场景] 的对话脚本。

角色：
- 角色A：[描述，性格]
- 角色B：[描述，性格]

情境：[背景故事]

要求：
- 对话自然，符合角色性格
- 控制在 [X] 轮对话以内
- 有明确的情境转折或信息揭示
```

### 29. 英文翻译与本地化

```text
请将以下英文内容翻译成中文。

原文：
[粘贴英文]

要求：
- 不是字对字翻译，而是让中文读者读起来自然
- 保留原文的语气和风格
- 专业术语第一次出现时保留英文原文
- 文化特定表达做本地化处理（如俚语翻译成对应的中文表达）
```

### 30. 视觉描述（给 AI 生图用）

```text
请帮我写一段 AI 绘图工具（如 Midjourney/DALL·E）能用的图像描述 prompt。

我想生成的画面：[用中文描述你想要的效果]
风格参考：[如“宫崎骏动画风格”“极简插画”“电影海报”]
重点元素：[人物/物体/场景的具体要求]
色调和氛围：[如“温暖/冷峻/未来感”]

输出：
1. 英文版 prompt（适合 Midjourney/Stable Diffusion）
2. 中文版 prompt（适合 DALL·E/通义万相）
```

## 使用技巧

1. **直接复制**：找到你要的模板，替换 `[]` 中的内容，发给 AI。
2. **先跑一次**：第一次不要太长，观察 AI 的反应再微调。
3. **保存好用的**：把效果好（≥4/5分）的版本存到自己的 prompt 文件夹。
4. **组合使用**：比如先用 #11 总结文章，再用 #16 解释其中的概念。
5. **不要 100% 照抄**：根据你的具体场景加约束、改格式。
