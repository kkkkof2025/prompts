# 附录 B：AI 术语表

这份术语表面向初学者。它不追求学术定义最完整，而追求你读书、看文档、使用工具时能快速理解。

## A

### Agent

能围绕目标进行计划、调用工具、观察结果并继续行动的 AI 系统。聊天机器人主要回答，agent 可以执行。

简单理解：

```text
聊天机器人：你问，它答。
Agent：你给目标，它计划、行动、检查、继续。
```

### A2A

Agent2Agent 的缩写，指 agent 与 agent 之间互操作和协作的协议方向。它关注不同 agent 如何发现彼此能力、交换任务状态和传递结果。

### Alignment

通常译为“对齐”。意思是让 AI 的行为更符合人类意图、价值、安全边界和使用规则。

## C

### Chain of Thought

常译为“思维链”。指模型在解决复杂问题时进行中间推理的方式。普通用户不需要强迫模型暴露完整推理过程，更实用的做法是要求它给出结论、依据、检查点和不确定性。

### Context Window

上下文窗口。模型一次能看到的输入范围，包括当前对话、文件片段、工具结果和系统说明。窗口大不代表一定理解得好，长资料仍需要结构化。

## E

### Embedding

把文本、图片等内容转换成向量表示的方法。常用于搜索、推荐、相似度比较和 RAG。

### Evaluation

评估。判断 AI 输出是否满足任务要求。可以是人工评分、自动测试、事实核验、格式检查或小型评测集。

## F

### Fine-tuning

微调。在已有模型基础上用特定数据继续训练，让模型更适合某类任务、风格或格式。微调不是解决所有问题的第一选择，很多问题用 prompt、RAG 或 skill 就够。

### Function Calling

函数调用或工具调用。模型根据任务决定调用外部函数，例如搜索、查数据库、运行代码或创建日程。

## G

### Guardrail

护栏。限制 AI 行为的规则、检查、过滤器或人工确认机制。比如不允许删除文件、不允许输出隐私、不允许直接给医疗诊断。

## H

### Hallucination

幻觉。AI 生成看似合理但不真实的信息。降低幻觉的关键是提供来源、要求标注不确定性、使用工具核验和建立评估。

### Handoff

交接。一个 agent 把任务转交给另一个更适合的 agent 或流程。例如“资料搜索 agent”把结果交给“写作 agent”。

## L

### LLM

Large Language Model，大语言模型。擅长处理文本、代码和结构化语言任务，也可以作为多模态系统的一部分。

### Long Context

长上下文。指模型可以处理很长输入。适合读长文档、代码库、会议记录，但仍需要目录、引用和分块策略。

## M

### MCP

Model Context Protocol，模型上下文协议。它提供一种让 AI 应用连接外部工具和数据源的标准化方式。

### Memory

记忆。让 AI 保存跨会话信息，例如用户偏好、项目背景、长期目标和历史经验。好的记忆需要写入、检索、更新和删除机制。

### Multimodal

多模态。模型能处理文本之外的信息，例如图片、音频、视频、文件、屏幕和表格。

## P

### Prompt

提示词。你给 AI 的任务说明。好的 prompt 通常包含目标、背景、约束、输出格式和验收标准。

### Prompt Engineering

提示词工程。设计、测试、评估和维护 prompt 的方法。它不只是写一句神奇指令，而是把任务说明写清楚。

## R

### RAG

Retrieval-Augmented Generation，检索增强生成。先从知识库检索相关资料，再让模型基于资料回答。适合私有知识和过时风险高的事实问题。

### Reasoning Model

推理模型。通常在复杂规划、数学、代码和多步骤问题上更稳，但可能更慢、更贵。

## S

### Skill

可复用能力包。通常包含说明、流程、模板、脚本、资源和边界。Skill 把经验从一次性 prompt 固化为可维护资产。

### System Prompt

系统提示。比用户普通消息更高优先级的规则，用于定义模型角色、行为边界、工具使用规则和安全要求。

## T

### Token

模型处理文本的基本单位。中文、英文、符号和代码都会被拆成 token。上下文长度和计费常与 token 有关。

### Tool Use

工具使用。AI 调用搜索、文件、代码、数据库、浏览器或 API 完成任务。工具能力越强，权限和审计越重要。

## V

### Vector Database

向量数据库。用于存储和检索 embedding，常用于 RAG 和语义搜索。

## 学术定义与日常用法的区别

AI 术语经常有两种用法：论文中的严格定义，和产品文档、社区讨论中的日常用法。初学时先掌握日常用法，遇到工程实现或研究论文时再回到严格定义。

## 遇到新术语时怎么问 AI

```text
请解释【术语】。
要求：
1. 先用一句话解释。
2. 再给一个生活类比。
3. 再说明它在 AI 系统中解决什么问题。
4. 最后列出它容易被误解的地方。
```
