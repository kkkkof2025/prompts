# 附录 D：常用检查清单

这些清单适合在真实使用前快速过一遍。

## 好 Prompt 检查清单

- [ ] 是否写清目标。
- [ ] 是否提供必要背景。
- [ ] 是否列出约束。
- [ ] 是否说明输出格式。
- [ ] 是否给出验收标准。
- [ ] 是否要求 AI 在信息不足时先提问。
- [ ] 是否避免让 AI 编造来源、数据或经历。

## 复杂任务工作流检查清单

- [ ] 是否把任务拆成多个阶段。
- [ ] 每个阶段是否有输入和输出。
- [ ] 是否设置人工确认点。
- [ ] 是否先计划再执行。
- [ ] 是否有最终自检。
- [ ] 是否记录可复用经验。

## AI 输出事实核验清单

- [ ] 事实是否有来源。
- [ ] 来源是否可靠。
- [ ] 日期是否足够新。
- [ ] 是否存在更权威的一手来源。
- [ ] 是否区分事实、推测和建议。
- [ ] 是否列出无法确认的信息。

## RAG/知识库检查清单

- [ ] 文档是否有清晰标题。
- [ ] 原始资料和总结是否分开。
- [ ] 重要内容是否有来源和日期。
- [ ] 是否删除或标记过时资料。
- [ ] 是否有权限控制。
- [ ] 回答是否标注引用依据。

## Skill 设计检查清单

- [ ] 这个任务是否会重复出现。
- [ ] 是否写明触发场景。
- [ ] 是否写明输入要求。
- [ ] 是否写明输出格式。
- [ ] 是否写明边界。
- [ ] 是否写明验收标准。
- [ ] 是否至少有一个示例。

## Agent 任务检查清单

- [ ] 目标是否明确。
- [ ] 工具权限是否最小化。
- [ ] 读写范围是否明确。
- [ ] 高风险动作是否需要人工确认。
- [ ] 是否能记录行动日志。
- [ ] 是否能回滚。
- [ ] 是否有完成标准。

## 个人 AI 记忆检查清单

- [ ] 是否只保存长期有用信息。
- [ ] 是否避免保存敏感信息。
- [ ] 是否记录来源和日期。
- [ ] 是否能删除过时记忆。
- [ ] 是否区分长期偏好和临时要求。
- [ ] 当前任务是否真的需要调用记忆。

## 团队 AI 治理检查清单

- [ ] 哪些数据可以输入 AI。
- [ ] 哪些数据禁止输入 AI。
- [ ] 哪些任务必须人工复核。
- [ ] 哪些工具被允许使用。
- [ ] 输出是否需要引用来源。
- [ ] 是否记录重要 AI 辅助决策。
- [ ] 是否有安全事件处理流程。

## 发布前检查清单

适合本书和其他开源文档项目。

- [ ] README 是否说明项目目标。
- [ ] 目录是否完整。
- [ ] 本地链接是否有效。
- [ ] 外部资料是否标注核验日期。
- [ ] 示例是否可复制。
- [ ] 是否说明贡献方式。
- [ ] 是否选择许可证。
- [ ] 是否避免泄露个人路径、密钥或私有资料。
