# 1.0 发布前总检查清单

最后维护：2026-05-12

本文档用于把《AI 学习方法全景书》从 0.7 草案推进到 1.0 稳定发布版。它不是写作清单，而是发布前的最终验收表：确认内容完整、链接可用、术语统一、外部事实已复核、教学和团队落地材料能闭环、版权与发布设置无明显缺口。

建议发布负责人在正式打 1.0 标签前，逐项勾选并记录证据。

## 八、1.0 发布决策

发布负责人在所有检查完成后填写。

### 发布条件

必须全部满足：

```text
□ 所有核心页面进入目录
□ 章节练习与验收映射表已更新
□ 前沿资料季度复核执行手册和示例记录已纳入维护流程
□ 前沿资料复核记录表已更新，或明确标注尚未联网复核
□ 本地链接检查通过
□ 占位标记检查通过
□ 术语一致性检查通过
□ Markdown lint 通过
□ 资源附录完成一次近期复核
□ 试读、课堂或团队试点反馈已经记录，或明确标注尚未验证的材料
□ README、LICENSE、CONTRIBUTING、ROADMAP、CHANGELOG 完整
□ 至少一名人工维护者完成通读
□ 没有未处理的高风险事实错误或安全误导
```

### 版本打标建议

如果通过，建议执行：

```text
1. 在 CHANGELOG.md 中新增 1.0.0 条目。
2. 将 ROADMAP 当前版本改为 1.0 稳定版。
3. 在 README 当前状态中标注 1.0 发布。
4. 创建 GitHub Release：v1.0.0。
5. 发布说明中列出：章节、案例、教学材料、团队落地路线、自动化检查。
```

### 暂缓发布条件

任一命中即建议暂缓：

```text
□ 核心章节缺失或结构不完整
□ 本地链接检查失败且未修复
□ 存在明显过时或无法确认的关键事实
□ 安全治理章节存在误导性建议
□ 教学或团队落地材料入口缺失
□ 人工通读发现重大问题未处理
```
