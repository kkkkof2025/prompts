# 章节复盘题与小测

这份材料用于自学、读书会和团队培训。每章读完后，先独立回答，再对照章节内容复盘。

## 使用方式

建议每章用 10 分钟：

```text
3 分钟：回答选择题或判断题。
4 分钟：回答开放题。
3 分钟：写下一个可执行行动。
```

## 第 0 章：学习路线图

小测：

1. AI 学习的四层能力是什么？
2. 为什么不建议一开始就做复杂 agent？
3. 一个最小实践循环包括哪些步骤？

复盘题：

```text
我现在最需要提升的是表达、拆解、复用还是判断？
我本周可以把哪个真实任务交给 AI 练习？
```

## 第 1 章：基础对话

小测：

1. 一个好问题通常包含哪五个部分？
2. 什么时候应该让 AI 先提问？
3. 角色设定真正有用的部分是什么？

复盘题：

```text
我最近一次 AI 对话失败，是缺少目标、背景、约束、标准还是输出格式？
```

## 第 2 章：AI 基本概念

小测：

1. 上下文窗口大是否等于模型一定理解得更好？
2. 幻觉更容易出现在哪些场景？
3. AI 系统除了模型，还包含哪些组件？

复盘题：

```text
我常问的问题中，哪些必须做事实核验？
```

## 第 3 章：Prompt 入门

小测：

1. Prompt 和一次普通提问有什么区别？
2. 示例和反例分别解决什么问题？
3. 为什么复杂任务要分阶段输出？

复盘题：

```text
请把一个“帮我优化一下”的弱 prompt 改成结构化 prompt。
```

3. 什么样的任务值得模板化？

复盘题：

```text

```

## 第 13 章：安全、伦理与治理


## 第 14 章：30 天实践计划

小测：

1. 30 天计划最终应该产出哪些东西？
2. 为什么要从基础对话开始，而不是直接学 agent？
3. 复盘问题中最重要的一题是什么？

复盘题：

```text
请从 30 天计划中选出最适合你本周开始的 3 天任务。
```

## 答案使用建议

这些题没有唯一答案。判断是否合格，可以看三点：

- 是否能用自己的话解释。
- 是否能举出真实任务例子。
- 是否能写出下一步行动。
