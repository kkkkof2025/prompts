# AI 数据准备实战指南

> AI 输出的质量上限由三个东西决定：数据的质量、prompt 的质量、模型的能力。其中，数据质量是最容易被忽视的一个。**垃圾进，垃圾出**（GIGO）在 AI 时代依然成立。

## 一、为什么数据准备很重要

### 1.1 两种典型失败
{: #1-1两种典型失败 }

**场景 1**：把原始 Excel 粘贴给 AI

```text
用户：请分析这个销售数据

销售记录
日期	    产品	    数量	金额
5/1	    A产品	   100  50000
5/2	     B产品     50   25000
5/3	   C产品 		 30   15000        # ← 空格不一致
5/4   A产品		- 	0				    # ← 无效行
5/5	   B产品 	   20   ???		    # ← 数据缺失
```

AI 回复："数据中存在不一致的格式，部分日期格式异常，两行数据缺失。我无法提供准确分析。建议您先整理数据格式。"

→ **不是 AI 不行，是数据没准备好。**

**场景 2**：把混在一起的信息一股脑丢给 AI

```text
用户：帮我整理一下上周的会议内容

上周我们开了三次会。周一讨论了新功能，张工说排期要到下个月，李经理不同意，觉得太慢。
然后周三我们又讨论了一次，这次加入了王总的要求，他想要加报表功能。
哦对了，周五还有个临时会议，但不是什么重要的事。
还有，周二我请假了没参加早会。周四下午的会取消了。
```

AI 回复了一篇冗长的总结，但漏掉了关键决策，还搞混了会议日期。

→ **信息没结构化，AI 梳理能力被浪费了。**

## 二、数据清洗清单

在把任何数据喂给 AI 之前，检查这5项：

```text
□ 1. 格式一致：日期、数字、单位统一了吗？
□ 2. 无缺失值：空行、空列、"N/A"、"???" 处理了吗？
□ 3. 无噪音：不相关的行、重复的内容删了吗？
□ 4. 结构化：文本是"人看"的格式还是"机器读"的格式？
□ 5. 有标注：AI 需要知道"这是什么"吗？
```

### 2.1 格式清洗示例
{: #2-1格式清洗示例 }

```text
❌ 原始：
日期: 5/1, 2026-5-2, 5月3号, 2026/05/04

✅ 清洗后：
日期: 2026-05-01, 2026-05-02, 2026-05-03, 2026-05-04
```

### 2.2 文本去噪
{: #2-2文本去噪 }

```text
❌ 原始文本（从网页复制）：
据最新研究表明           ← 多个空格
AI技术的发展日新月异。
■ 相关内容：点击此处了解详情  ← 网页导航
[广告] 限时优惠！             ← 广告
（本文共3287字，阅读需要10分钟） ← 元数据

✅ 清洗后：
据最新研究表明，AI技术的发展日新月异。
```

## 三、结构化输入模板

### 3.1 会议记录 → 结构化输入
{: #3-1会议记录结构化输入 }

```text
# 使用模板前（原始转录）：
"我们讨论了一下新功能的事，张工说大概要两周，李经理觉得太长了，
希望能压缩到一周半。然后大家又讨论了一下测试的事..."

# 使用模板后：
【会议信息】
- 日期：2026-05-20
- 主题：新功能排期讨论
- 参会：张工、李经理

【讨论要点】
1. 排期：张工提 2 周 → 李经理要求压缩 → 初步妥协 1.5 周
2. 测试：确认需要增加自动化测试，预计额外 2 天

【决议】
1. 排期定 1.5 周（5/21-6/1）
2. 测试时间从排期中预留

【待办】
- 张工：5/21 前出详细排期表
- 李经理：5/21 前确认资源分配
```

**为什么这样更好**：AI 不用猜测"谁说了什么""这事定没定"。

### 3.2 需求描述 → 结构化输入
{: #3-2需求描述结构化输入 }

```text
❌ 原始：
帮我做个用户管理系统。要能注册登录，管理员可以看所有用户，
普通的只能看自己。最好做得好看一点。

✅ 结构化：
# 用户管理系统需求

## 角色
- 管理员：查看所有用户、启停账户
- 普通用户：注册、登录、查看/修改自己信息

## 功能列表
1. 注册：邮箱+密码，邮箱验证
2. 登录：邮箱+密码，5次错误锁定15分钟
3. 用户列表（管理员）：分页、搜索、导出
4. 个人信息（用户自己）：查看、修改

## 非功能需求
- 响应时间：< 2 秒
- 密码加密存储
- 操作日志记录

## 不用做的
- 不需要社交登录（微信/QQ）
- 不需要角色自定义（只有管理员和用户两种）
```

## 四、RAG 知识库数据准备

如果你的 AI 需要从文档中检索信息回答，数据准备就更关键了。

### 4.1 文档分块原则
{: #4-1文档分块原则 }

```text
❌ 按字数切（500字一块）：
问题："退货政策是什么？"
检索到：[退货政策第一段：退货需要保持原包装...]
            → 不完整，只看到第一段

✅ 按语义切（一个问题一块）：
# 退货政策
## 退货条件
满足以下条件之一可以退货：...

## 退货流程
1. 登录账户
2. 找到订单
3. 点击"申请退货"
4. ...

## 退款时间
支付宝/微信：3-5个工作日
银行卡：5-15个工作日
```

### 4.2 知识库文档模板
{: #4-2知识库文档模板 }

```text
# 文档标题（一个问题一个文档最好）

## 适用范围
这个文档回答什么问题？不回答什么？

## 核心内容
用清晰的段落回答问题

## 常见误区
人们最容易搞错的部分

## 相关文档
链接到相关的其他文档

## 最后更新
2026-05-20 | 版本 1.2 | 修改人：张三
```

### 4.3 元数据标注
{: #4-3元数据标注 }

```markdown
---
title: "退货政策"
category: "售后"
keywords: ["退货", "退款", "退换"]
last_updated: "2026-05-20"
version: "1.2"
owner: "客服部"
---
```

## 五、用 AI 帮你准备数据

### 5.1 让 AI 清洗数据
{: #5-1让AI清洗数据 }

```text
你是一个数据整理助手。我给你一段原始数据，请帮我：

1. 统一日期格式为 YYYY-MM-DD
2. 去除空行和不相关内容
3. 检测并标注异常值
4. 输出为 Markdown 表格

原始数据：
{粘贴你的数据}
```

### 5.2 让 AI 结构化信息
{: #5-2让AI结构化信息 }

```text
我有以下散乱的信息，请帮我整理成结构化格式：

{粘贴会议记录/聊天记录/邮件}

请输出：
1. 主题（一句话）
2. 关键人物和他们的立场
3. 决议事项（表格）
4. 待办事项（表格：任务|负责人|截止日期）
5. 你发现的矛盾点或不确定之处
```

## 六、常见失败模式与修复

| 失败模式 | 表现 | 修复方式 |
|---------|------|---------|
| 格式混乱 | AI 理解错日期/数字 | 统一格式后再喂 |
| 信息过载 | AI 遗漏关键信息 | 先分类，分批给 |
| 缺少上下文 | AI 误解意图 | 补充背景和目标 |
| 噪音干扰 | AI 被无关内容带偏 | 先做文本清洗 |
| 缺少标注 | AI 不知道谁说了什么 | 加角色标签 |
| 一次性给太多 | AI 处理不完整 | 拆分+分批 |

---

## 七、检查清单

每次把数据喂给 AI 前：

- [ ] 数据格式统一了吗？
- [ ] 空值/异常值处理了吗？
- [ ] 不相关内容删了吗？
- [ ] 关键信息有标注吗？
- [ ] 这个数据量 AI 一次能处理吗？（不超过上下文窗口的 70%）
- [ ] 需要分批给吗？
- [ ] 我期望 AI 输出什么格式，说清楚了吗？
