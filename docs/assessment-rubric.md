# AI 能力评估量表

这份量表用于自评、读书会、团队培训和阶段复盘。它不是考试，而是帮助你判断自己下一步该练什么。

如果你要把个人能力扩展到团队流程，可以配合 [团队 AI 落地手册](team-adoption-playbook.md) 使用。

## 使用方式

每个维度按 1-5 分评分：

| 分数 | 含义 |
| --- | --- |
| 1 | 几乎不会，需要示例才能开始 |
| 2 | 能做简单任务，但不稳定 |
| 3 | 能独立完成常见任务 |
| 4 | 能处理复杂任务并建立模板 |
| 5 | 能教别人、设计流程和治理边界 |

建议每两周评估一次。不要追求所有维度满分，先提升最影响你真实任务的维度。

## 维度 1：表达目标

| 分数 | 表现 |
| --- | --- |
| 1 | 经常只说“帮我优化”“总结一下” |
| 2 | 能说出任务，但背景和标准不清 |
| 3 | 能写出目标、背景、约束和输出格式 |
| 4 | 能根据不同读者和场景调整任务说明 |
| 5 | 能把模糊需求转成可执行任务说明书 |

练习：

```text
把最近 3 个弱 prompt 改写成五要素 prompt。
```

## 维度 2：任务拆解

| 分数 | 表现 |
| --- | --- |
| 1 | 习惯把复杂任务一次性交给 AI |
| 2 | 知道要分步骤，但步骤不稳定 |
| 3 | 能把任务拆成 3-5 步 |
| 4 | 能为每一步设置输入、输出和检查点 |
| 5 | 能设计可复用工作流并培训他人使用 |

练习：

```text
把一个每周重复任务拆成“收集-整理-生成-检查-复盘”五步。
```

## 维度 3：Prompt 设计

| 分数 | 表现 |
| --- | --- |
| 1 | 依赖网上复制的 prompt |
| 2 | 能修改角色和语气 |
| 3 | 能使用示例、反例和格式约束 |
| 4 | 能建立自己的 prompt 模式库 |
| 5 | 能根据失败结果系统迭代 prompt |

练习：

```text
为同一个任务写 3 个 prompt 版本，并用同一评分表比较。
```

## 维度 4：验证与评估

| 分数 | 表现 |
| --- | --- |
| 1 | 主要凭感觉判断 AI 回答好坏 |
| 2 | 偶尔要求 AI 自查 |
| 3 | 能用来源、测试或评分表验证 |
| 4 | 能建立小型评测集 |
| 5 | 能为团队建立评估流程和质量门槛 |

练习：

```text
为一个常用任务建立 10 条测试样例和 5 项评分标准。
```

## 维度 5：知识库与 RAG

| 分数 | 表现 |
| --- | --- |
| 1 | 每次都临时粘贴资料 |
| 2 | 有资料文件，但结构混乱 |
| 3 | 能建立小型知识库并要求 AI 引用依据 |
| 4 | 能维护来源、日期、版本和权限 |
| 5 | 能设计团队知识库和 RAG 评估流程 |

练习：

```text
建立 3 个知识库文件：profile.md、project.md、style.md，并让 AI 只依据它们回答。
```

## 维度 6：Skill 沉淀

| 分数 | 表现 |
| --- | --- |
| 1 | 每次从头写 prompt |
| 2 | 保存了一些模板，但缺少边界 |
| 3 | 能写出包含输入、输出和验收标准的 skill |
| 4 | 能测试和迭代 skill |
| 5 | 能为团队维护 skill 库 |

练习：

```text
把一个重复任务写成 skill/card，并用真实材料测试。
```

## 维度 7：Agent 使用

| 分数 | 表现 |
| --- | --- |
| 1 | 把 agent 当更强聊天工具 |
| 2 | 会让 agent 执行任务，但边界不清 |
| 3 | 能写目标、工具、禁止事项和验收标准 |
| 4 | 能设置权限、日志、确认点和回滚方式 |
| 5 | 能设计多 agent 协作流程和审计机制 |

练习：

```text
为一个低风险任务写 agent 工作说明，并列出必须人工确认的动作。
```

## 维度 8：安全与治理

| 分数 | 表现 |
| --- | --- |
| 1 | 不清楚哪些信息不能上传 |
| 2 | 知道敏感信息不能上传，但没有清单 |
| 3 | 有个人 AI 安全规范 |
| 4 | 能为团队定义数据、工具和复核规则 |
| 5 | 能建立日志、权限、事件响应和定期审查流程 |

练习：

```text
写一份个人或团队 AI 使用规范，至少包含禁止上传数据和必须人工复核任务。
```

## 总分解释

| 总分 | 阶段 | 建议 |
| --- | --- | --- |
| 8-15 | 入门前期 | 先练基础对话和五要素 prompt |
| 16-25 | 初级 | 重点练工作流和输出验证 |
| 26-32 | 中级 | 开始建立模板、知识库和 skill |
| 33-38 | 进阶 | 学习 agent 边界、评估和治理 |
| 39-40 | 教练级 | 可以带团队建立 AI 工作系统 |
