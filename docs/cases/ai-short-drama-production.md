# AI 短剧制作全流程实战

> 一个完整的端到端案例：如何用 AI 从零到一制作一部科幻教育短剧，实现「一人即团队」的工业化生产。
>
> 本案例基于真实生产流程，涵盖从创意提案到多平台分发的全部环节。它不仅是工具清单，更是一套可复制的生产体系。

---

## 一、核心认知：一人即团队

传统短剧制作需要编剧、分镜师、美术、拍摄、剪辑、配音、运营至少 7 个岗位。AI 的成熟让一个人通过标准化流程 + 固定工具链，就能完成全链路。

| 传统岗位 | AI 替代方案 | 效率提升 |
|---------|------------|---------|
| 编剧 | GPT / DeepSeek 生成剧本+分镜 | 5-10× |
| 分镜师 | Midjourney / 即梦 生成分镜图 | 10× |
| 美术/概念设计 | Midjourney 生成角色+场景资产 | 10× |
| 拍摄 | 可灵 / Pika 图生视频 | 颠覆性 |
| 配音 | ElevenLabs / TTS 语音生成 | 即时 |
| 剪辑 | 剪映 AI 自动字幕+踩点 | 3-5× |
| 运营 | AI 生成标题+封面+多版本 | 5× |

**综合制作成本降至传统模式的 1/10，交付周期从 30 天压缩至 3-7 天。**

## 二、五大环节生产线

### 环节 1：创意提案（2-4 小时）

**核心原则**：选题决定 80% 的成败。AI 降低制作成本，但创意筛选不可替代。

#### 1.1 提案五要素模板
{: #1-1提案五要素模板 }

| 要素 | 内容要求 | 示例（《AI课堂走入未来生活》） |
|------|---------|------|
| 一句话梗概 | 高概念+强钩子 | 在AI教育普及的近未来，内向少年林小宇通过"隐藏任务"发现AI系统背后的秘密 |
| 受众与平台 | 精准画像+渠道 | 12-25岁学生 / 抖音竖屏 + B站横屏 |
| 视觉风格 | 3-5 张参考图+风格关键词 | 蓝紫霓虹柔光+简约科技风+温暖明亮 |
| 前三集大纲 | 每集有目标+冲突+悬念 | EP1:觉醒 → EP2:探索 → EP3:抉择 |
| AI 差异化亮点 | 你比传统制作强在哪 | 单人日产，成本 1/10，AI教育话题自带传播 |

#### 1.2 AI 生成提案的万能提示词
{: #1-2AI生成提案的万能提示词 }

```text
你是一个资深的短剧策划，擅长结合当下热点创作爆款短剧。
我的核心关键词是 [教育/科幻/成长/3分钟/学生群体/近未来/温暖治愈]，
请为我生成 3 个不同风格的短剧提案，每个提案都要包含：
剧名、故事梗概、适配平台、AI视觉风格建议。
```

#### 1.3 多提案衍生法
{: #1-3多提案衍生法 }

一个灵感 → 换叙事视角 → 3 个差异化方向：

| 方向 | 风格 | 核心差异 |
|------|------|---------|
| 成长悬疑向 | 蓝紫科技风 | 主角视角，探索系统秘密 |
| 治愈喜剧向 | 明亮活泼 | AI 导师视角，人机伙伴关系 |
| 现实反思向 | 写实冷静 | 系统管理员视角，教育公平探讨 |

### 环节 2：剧本与分镜（4-8 小时/集）

#### 2.1 剧本+分镜一站式生成
{: #2-1剧本分镜一站式生成 }

```text
你是专业的科幻短剧编剧，为我的IP《AI课堂走入未来生活》创作单集剧本与分镜表。

IP背景：[近未来教育科技，主角16岁学生林小宇，风格温暖治愈+轻科幻]
单集时长：3分钟，约10-12个镜头。
核心剧情主题：[填写单集核心剧情]

请按以下要求生成：
1. 完整单集剧本（角色设定、剧情梗概、台词对话）
   - 前3秒必须有钩子
   - 每15-30秒一个小冲突/反转
   - 结尾留悬念引导追更
2. 结构化分镜表（含：场次、景别、画面描述、台词/字幕、时长、音效/转场）
3. 风格：蓝紫霓虹+简约科技风，台词自然不教条
```

#### 2.2 分镜表模板
{: #2-2分镜表模板 }

| 场次 | 景别 | 画面描述 | 台词/字幕 | 时长(s) | 音效 |
|------|------|---------|----------|---------|------|
| 1 | 全景 | 未来教室全景，蓝紫柔光 | 旁白："2077年，AI课堂成为标配" | 5 | 科技启动音 |
| 2 | 中景 | 主角盯全息屏，表情疑惑 | 主角："这道题…AI的解法好像哪里不对？" | 8 | 键盘敲击声 |
| 3 | 特写 | 全息屏代码异常波动 | 字幕：系统错误 | 3 | 数据流波动音 |

### 环节 3：资产生产（8-16 小时，一次性投入）

核心任务：搭建可复用的视觉素材库，确保角色形象和场景风格不"跑偏"。

#### 3.1 角色资产（固定 Seed 值）
{: #3-1角色资产固定Seed值 }

```
主角林小宇定妆照：
16-year-old Asian male student, short black hair, white hoodie with tech patterns,
kind eyes, soft studio lighting, futuristic classroom bg, realistic design,
8K, portrait style, --ar 2:3 --seed 67890

AI导师全息形象：
Holographic AI tutor, glowing blue-purple humanoid form, floating mid-air,
soft light radiating, minimalist sci-fi, 8K, --ar 1:1 --seed 13579
```

#### 3.2 场景资产（统一色调和光影）
{: #3-2场景资产统一色调和光影 }

```
未来科技教室全景：
Empty futuristic classroom, holographic desks, large holographic blackboard,
soft blue-purple ambient light, clean minimalist sci-fi design,
wide-angle cinematic, 8K, photorealistic, --ar 16:9 --seed 12345
```

#### 3.3 关键技巧
{: #3-3关键技巧 }

- **Seed 一致性**：同一角色/场景的所有生成都复用同一个 Seed，确保形象稳定
- **风格关键词统一**：所有提示词带上"蓝紫霓虹柔光 / 简约科技风 / 温暖明亮"
- **分类归档**：按"角色/场景/道具"分类保存，后续直接调用

---

### 环节 4：视频生成（10-15 小时/集）

#### 4.1 核心方法：逐镜头图生视频
{: #4-1核心方法逐镜头图生视频 }

**3:1 生成比例**：每个最终可用镜头，生成 3 个备选 → 从 30 个片段中选 10 个最稳定的。

#### 4.2 避坑技巧
{: #4-2避坑技巧 }

| 问题 | 解决方案 |
|------|---------|
| 画面抖动/扭曲 | 每次只生成 3-5 秒，避免大幅度动作 |
| 角色脸崩 | 图生视频时提供参考图，固定角色 Seed |
| 风格跳变 | 统一提示词关键词，同一场景复用 Seed |
| 生成失败 | 提前准备备用分镜，失败镜头用环境镜头替代 |

#### 4.3 视频生成提示词模板
{: #4-3视频生成提示词模板 }

```
基于提供的概念图生成动态视频，风格延续「蓝紫霓虹+简约科技风」。
镜头：[固定/缓慢推进/轻微摇镜]，时长 3-5 秒
动态细节：(具体描述，如"全息屏幕微光闪烁")，无大幅度动作
氛围：温暖明亮，无抖动，8K电影级质感，--motion 1
```

---

### 环节 5：后期合成与发布（4-6 小时/集）

#### 5.1 标准化后期流程
{: #5-1标准化后期流程 }

1. **素材拼接**：按分镜顺序导入剪映
2. **套用模板**：调色预设 + 字幕样式 + BGM 一键匹配
3. **音频合成**：AI 配音 + 环境音效，音量平衡
4. **多版本导出**：横屏正片 + 竖屏剪辑版 + 30 秒预告片

#### 5.2 剪辑模板参数（一次设定，全集复用）
{: #5-2剪辑模板参数一次设定全集复用 }

| 设置项 | 参数 |
|--------|------|
| 分辨率 | 1080P 16:9（横屏）/ 9:16（竖屏） |
| 字幕字体 | 思源黑体 Bold，白色，蓝紫外描边 |
| 调色 | 亮度+5，对比度+8，色温-5（冷调），色调+5（偏紫） |
| BGM | 轻柔电子风，音量 15-20% |
| 片头 | 主视觉概念图推进，3 秒 |
| 片尾 | 黑底+数据流粒子，"下集预告"+账号ID，2 秒 |

#### 5.3 发布与复盘
{: #5-3发布与复盘 }

- **A/B 测试**：准备 2-3 套标题+封面，测试点击率
- **数据复盘指标**：前 3 秒完播率、整体完播率、互动率、追更率
- **迭代优化**：根据数据调整下一集节奏、钩子、话题

## 三、从新手到熟练：时间成本演进

| 阶段 | 单集耗时 | 关键特征 |
|------|---------|---------|
| 单人新手 | 40-60 小时 | 熟悉全流程，大量试错 |
| 熟练单人 | 20-30 小时 | 模板化生产，资产库复用 |
| 3 人小团队 | 7-10 天/集 | 分工并行 |
| AI 赋能极致 | <5 小时/集 | 自动化，人工只做审核和创意 |

**提效关键**：每做完一集，沉淀一个模板（剧本/分镜/剪辑/标题），下一集基于模板优化而非从零开始。

## 五、为什么这个案例对 AI 学习者重要

这个案例展示的不是"某个 AI 工具怎么用"，而是**一套完整的 AI 思维模型**：

1. **工作流思维**：把复杂任务（做一部短剧）拆成可执行的串行环节（Ch04）
2. **Prompt 工程**：每个环节都有精心设计的提示词模板（Ch03）
3. **评估迭代**：用 A/B 测试和数据复盘持续优化（Ch05）
4. **知识管理**：资产库 = 视觉 RAG（Ch06）
5. **可复用 Skill**：提示词模板、剪辑预设、分镜格式都是 skill 的实例（Ch07）
6. **成本意识**：追求的不是"AI 能做"，而是"AI 比我做得更快更好"（Ch05）
