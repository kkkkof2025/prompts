# 分角色学习路径

不同读者学习 AI 的目标不同，不必所有人都按同样顺序读完。下面给出几条路线。

## 路线 1：零基础普通用户

目标：

能把 AI 用到学习、写作、资料整理和日常工作中。

阅读顺序：

1. [第 0 章：学习路线图](chapters/00-learning-map.md)
2. [第 1 章：从最基本的对话开始](chapters/01-dialogue-basics.md)
3. [第 3 章：Prompt 入门](chapters/03-prompt-basics.md)
4. [第 4 章：结构化 Prompt 与工作流](chapters/04-prompt-workflows.md)
5. [真实应用案例](case-studies.md)
6. [练习参考答案](appendix-exercise-answers.md)

7 天最小任务：

```text
第 1 天：写出 5 个你想让 AI 帮忙的真实任务。
第 2 天：用五要素改写一个 prompt。
第 3 天：让 AI 先问你 3 个澄清问题。
第 4 天：用 AI 整理一篇文章。
第 5 天：用 AI 生成一个学习计划。
第 6 天：让 AI 自查并修改一次输出。
第 7 天：保存 3 个最有用模板。
```

## 路线 2：职场效率提升

目标：

把 AI 用到会议、邮件、周报、调研、方案和复盘中。

阅读顺序：

1. [第 1 章：从最基本的对话开始](chapters/01-dialogue-basics.md)
2. [第 4 章：结构化 Prompt 与工作流](chapters/04-prompt-workflows.md)
3. [第 5 章：模型选择、验证与评估](chapters/05-evaluation.md)
4. [第 7 章：Skills，把经验固化成能力](chapters/07-skills.md)
5. [常用检查清单](appendix-checklists.md)
6. [Prompt 模式实践模板](../examples/prompt-patterns.md)

建议先做的 3 个模板：

- 会议纪要模板。
- 周报整理模板。
- 资料分析模板。

## 路线 3：产品、运营和内容

目标：

用 AI 做用户研究、竞品分析、内容生成、实验设计和数据解释。

阅读顺序：

1. [第 3 章：Prompt 入门](chapters/03-prompt-basics.md)
2. [第 4 章：结构化 Prompt 与工作流](chapters/04-prompt-workflows.md)
3. [第 5 章：模型选择、验证与评估](chapters/05-evaluation.md)
4. [第 6 章：工具调用、RAG 与知识库](chapters/06-tools-rag.md)
5. [真实应用案例](case-studies.md)
6. [AI 术语表](appendix-glossary.md)

重点练习：

```text
1. 把 20 条用户反馈分类。
2. 用对比矩阵分析 3 个竞品。
3. 把一次访谈整理成用户需求和产品机会。
4. 为一个功能写 3 个不同定位的文案版本。
```

7. [代码库问答连续案例](cases/codebase-rag-skill-agent-memory.md)

重点练习：

```text
1. 让 AI 先读代码再写计划。
2. 为 bug 修复任务写 agent 工作说明。
3. 建立 10 条代码任务评测集。
4. 设计一个最小 RAG 文档问答流程。
5. 把代码修复经验沉淀成 bug triage skill。
```

目标：

建立团队 AI 使用规范、知识库、评估和治理流程。

阅读顺序：

1. [第 12 章：AI 前沿发展全景](chapters/12-frontier-landscape.md)
2. [第 13 章：安全、伦理与治理](chapters/13-safety-governance.md)
3. [第 6 章：工具调用、RAG 与知识库](chapters/06-tools-rag.md)
4. [第 8 章：Agent，从聊天到行动](chapters/08-agents.md)
5. [常用检查清单](appendix-checklists.md)
6. [项目维护指南](maintenance-guide.md)

30 天团队落地任务：

```text
第 1 周：确定允许使用 AI 的任务和禁止上传的数据。
第 2 周：建立 3 个团队常用 prompt 模板。
第 3 周：建立一个小型内部知识库试点。
第 4 周：建立人工复核、引用和日志规则。
```

```text
3. 每季度检查前沿资料。
4. 每年重新审查学习路径。
```

```text
1. 把一节课拆成学习目标、课堂活动和验收标准。
2. 把匿名化作业反馈沉淀成 teaching-feedback skill。
3. 为助教 agent 写清只读资料、写草稿和人工确认边界。
4. 写一份教学 memory 的禁止保存清单。
```
