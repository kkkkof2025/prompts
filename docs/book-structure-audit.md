# 书籍结构审计与内容健康治理

最后审计：2026-05-22

这页用于回答三个维护问题：书里还有没有遗漏、哪些内容可以继续补、哪些内容看起来重复但其实分工不同。它不是一次性报告，而是后续每轮继续完善时的结构参考。

## 审计范围

本轮审计以这几类材料为准：

- MkDocs 导航：`mkdocs.yml` 中读者能看到的在线阅读结构。
- 完整目录：`docs/SUMMARY.md` 中书稿、案例、模板和维护材料的总入口。
- 电子书导出清单：`scripts/export-ebook.ps1` 中离线版会合并的文件。
- 内容健康扫描：`scripts/content-health-report.ps1` 输出的短页、长页、章节结构和动态事实候选。
- 维护记录：`README.md`、`MEMORY.md`、`ROADMAP.md` 和 `CHANGELOG.md` 中对当前状态和下一步的描述。

`.github/`、`.workbuddy/`、构建目录和临时目录不属于书稿内容；它们不应该干扰正文健康判断。

## 重复内容判断

有些页面主题相近，但不能简单删除。更稳妥的做法是判断它们承担的读者任务是否不同。

| 看起来相近的内容 | 实际分工 | 处理方式 |
| --- | --- | --- |
| Event Sourcing 与事件日志样例 | 前者解释架构模式，后者给可运行事件流和回放脚本 | 保留并互链 |
| Observability / Tracing 与 Trace 样例 | 前者解释可观测性框架，后者给 JSONL、SQLite、runtime log、SDK 接入路径 | 保留分层结构，样例页继续增加运行证据 |
| OpenClaw 多 agent 联动与超级大脑架构 | 前者偏教程和部署路径，后者偏系统设计和长期推演 | 保留两个入口，避免一个页面过重 |
| 七层 AI 文明架构与第 12 章前沿全景 | 第 12 章是概览，七层架构是用户思想框架的专题展开 | 在第 12 章做入口，不把七层内容压缩成一节 |
| 模型概览与模型选型案例 | 模型概览讲能力地图，选型案例讲任务约束和评测方式 | 保留，避免把模型事实和决策方法混在一起 |
| 维护指南、自动化维护方案、本页 | 维护指南讲规则，自动化方案讲流水线，本页讲结构健康和内容取舍 | 保留，并在维护入口互链 |

## 继续补充的优先级

1. **角色案例扩写**：学生、教师、运营、产品、工程、管理者案例可以继续补“失败版本、修正路径、验收证据、适用边界”。这些页面不是错误缺口，但仍有扩写空间。
2. **基础章节例子增强**：第 0-5 章面向初学者，后续可补更生活化的“错误提问 -> 改写 -> 验收”案例。
3. **OpenClaw 试跑材料**：继续补统一 skill 安装、任务黑板、飞书/Telegram/云文档同步、CLI adapter、失败回滚和人工审批日志。
4. **前沿架构样例链**：继续补 Outbox relay worker、消费端去重表、Saga 补偿动作、durable timer、runtime log 到日志平台字段映射。
5. **教学验证材料**：用真实读书会、课堂试跑或团队试点反馈替换部分示范样例，保留匿名化规则。

## 新概念：内容健康治理

内容健康治理不是单纯排版，也不是只看字数。它是一套长期维护书稿的工程化做法：

- **可达性**：读者能不能通过导航、目录、首页、主题索引或搜索找到页面。
- **完整性**：页面是否有足够的定义、案例、失败方式、练习或下一步入口。
- **去重判断**：主题重复时，是否能说明每个页面解决的读者任务不同。
- **动态事实复核**：涉及模型、协议、SDK、产品能力、安全建议时，是否有核验日期和来源。
- **维护闭环**：新增页面是否同步到导航、目录、导出清单、README、路线图、变更记录和记忆。

这类治理适合交给脚本发现候选问题，但最终是否扩写、合并、拆分或保留，仍需要人工判断。原因是一本书的结构不只由文件数量决定，还取决于学习顺序、案例节奏、读者角色和风险边界。

## 每次继续完善时的检查顺序

```text
1. 先看 mkdocs.yml：新增页面是否能从线上左侧导航到达。
2. 再看 docs/SUMMARY.md：完整目录是否有稳定入口。
3. 再看 scripts/export-ebook.ps1：离线版是否遗漏主要页面。
4. 再跑 content-health-report：短页、长页、章节结构和动态事实候选是否合理。
5. 最后更新 README、ROADMAP、CHANGELOG、MEMORY：让读者和维护者知道变化在哪里。
```

如果本轮只修格式或脚本，仍要记录“本轮是否新增概念”。如果没有新增，要说明原因；如果新增了，要说明它属于事实、来源解释、本书判断还是待复核推演。
