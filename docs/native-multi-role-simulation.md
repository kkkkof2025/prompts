# 原生角色联动：用 Prompt 搭建 AI 生产流水线

> 不需要 OpenClaw、Coze、Dify——用纯 Prompt 就能让 AI 扮演不同专业角色，
> 把上一个角色的输出，变成下一个角色的输入，搭出一条完整的生产流水线。
>
> **这就是"原生"的含义**：你不需要任何平台，只需要一个聊天框 + 精准的角色指令。

---

## 一、核心思想：上游输出 → 下游输入

角色联动（Role Chaining）的本质是**把复杂任务拆成专业阶段，每个阶段配一个专门的 AI 角色，链式传递**：

```
[角色A：编剧] → 剧本 → [角色B：角色设计师] → 人物设定 → [角色C：分镜师] → 分镜表 → [角色D：视频生成] → 成片
```

每一个角色：
- 有一份**精确的角色指令**（不是泛泛的"你是一个编剧"，而是"你是有3年经验的都市情感编剧，擅长…"）
- 输出是**结构化的、明确的**（不是聊天，是可被下一个角色消费的物料）
- 下游角色**直接引用上游的产出**

这和"多Agent对话协作"完全不同——角色之间**不对话、不协商、不相互纠错**。他们是工厂流水线上的工序，不是会议室里的同事。

## 二、经典案例：AI 短剧全流程联动

以下是真实可用于生产的四角色联动流水线（全部基于 DeepSeek / 豆包 / 即梦）。

### 2.1 角色一：编剧——产出完整剧本

```
你是有3年创作经验的编剧，擅长都市情感赛道，深谙快节奏强冲突套路。

请创作一部短剧剧本，要求：
1. 人设：男主是财团执行总裁，女主是公司新任秘书，女二是男主的病弱白月光
2. 节奏：快，每集一个核心冲突
3. 台词：直白带情绪，避免散文式表达
4. 动作：用指令式描写
5. 风格：冲突、解谜、反转

输出：完整第一集剧本（含场景、对话、动作描写）
```

**关键**：编剧的输出是整个流水线的**唯一事实来源**。后面所有角色都从这里取数据。

### 2.2 角色二：人物形象设计师——从剧本提取角色设定

```
电影级角色建模专家

请根据以下剧本，为每个主要角色输出设定表：

【输入剧本】
{粘贴角色一的完整剧本}

【输出要求】严格按以下模板，每个角色一份：

- 姓名 | 性别 | 确切年龄 | 身份职业 | 核心性格
- 画幅构图：横向 16:9，纯白背景，无文字
- 视觉风格：二次元动漫风，极高画质，电影级光效
- 左侧特写：面部高清特写（中国人、确切年龄感、黑色/自然发色、
  眼睛深棕或黑色、皮肤纹理自然）
- 右侧三视：全身标准三视图（正面、侧面、背面）
- 服饰设计：上身/下身/鞋履，款式材质颜色必须有显著角色差异，
  严禁撞衫
```

**联动要点**：角色二的输入 = 角色一的输出。人物形象必须忠于剧本中的描写，不凭空添加。

### 2.3 角色三：三视图生成——把设定变成视觉资产

将角色二的输出**逐一粘贴**到图像生成工具（即梦/豆包/Midjourney），生成角色三视图。

这不是"和AI聊天"，而是**把上游的结构化数据当作下游的参数**：

```
输入 = "左侧特写：女性，27岁，面容清秀但透出疲惫感。黑色中长发，深棕色眼睛，
        肤色冷白皮……上身燕麦色宽松V领针织开衫……"
        ↓
工具 = 即梦 / 豆包 / Midjourney
        ↓
输出 = 角色三视图 + 面部特写（4张/角色）
```

### 2.4 角色四：分镜师——剧本 + 角色设定 → 15秒分镜脚本

```
顶级影视导演与分镜规划专家

请将以下剧本拆解为15秒/镜头的电影级分镜脚本。

【输入材料】
- 剧本：{粘贴角色一的完整剧本}
- 角色设定：{粘贴角色二的人物设定摘要——姓名、外貌、服装}

【输出要求：15秒分镜表】
每个分镜包含：
- 分镜序号：[核心冲突点描述]
- 场景描述：[地点/光影/人物状态]
- 0-4秒：【镜头语言】动作 + 画外音/台词
- 4-8秒：【镜头语言】细节反应 + 台词
- 8-12秒：【镜头语言】情绪转折
- 12-15秒：【镜头语言】定格 + 衔接下一个分镜的趋势

运镜词库（必须使用）：极焦特写、近景推轨、环绕摇镜、慢动作、手持震动
音画分离：台词时人物张嘴对口型，画外音时嘴唇闭合仅用微表情
```

**联动要点**：分镜师的输入**同时包含**角色一（剧本）和角色二（角色设定）的输出。人设不能凭空捏造——苏眠穿什么、陈序什么样，必须和角色二的设定一致。

### 2.5 角色五：视频生成 + 剪辑——最终交付

分镜表输出后，逐镜送入即梦/可灵生成视频，剪映拼接合成。

```
输入 = 15个分镜 × 分镜描述 + 角色参考图
        ↓
工具 = 即梦 / 可灵 + 剪映
        ↓
输出 = 完整短剧成片
```

## 三、角色联动的四条铁律

从上面的流水线可以总结出通用原则：

### 3.1 角色不对话，只传递结构化输出

❌ 角色A问角色B："你觉得这个设计怎么样？"
✅ 角色A输出剧本 → 角色B读取剧本 → 角色B输出人物设定

每一个角色的输出是**文档**，不是**对话**。下游角色拿到文档就开工，不需要理解上下文。

### 3.2 输入格式 = 输出格式

上一个角色的输出结构，必须匹配下一个角色的输入格式。

比如：角色二输出 `姓名|性别|年龄|外貌|服装`，角色四的分镜表中需要引用这些字段。如果你让角色二输出自由文本而不是结构化表格，角色四就会瞎编。

### 3.3 角色指令必须包含"输入来源说明"

每个角色提示词里一定要告诉它：**你的输入是什么、从哪来**。

```
❌ 弱指令："请设计角色形象"
✅ 强指令："请根据以下剧本 {粘贴} 中的描写，为每个角色输出设定表。
        不要凭空添加剧本中没有的特征。"
```

### 3.4 中途不要改上游输出

如果你在角色三发现角色二的人设有问题——**不是让角色三去改，而是回到角色二重新生成**。

这是和"多Agent对话协作"最本质的区别：角色之间不允许互相覆盖对方的产出。上游错了就回上游修，不在下游打补丁。

## 四、通用联动模板

不只是短剧——任何需要多步骤专业处理的任务，都可以搭流水线。

### 4.1 调研报告流水线

```
[研究员] → 原始资料摘要
    ↓
[分析师] → 关键发现 + 数据可视化描述
    ↓
[写作者] → 完整报告正文
    ↓
[审校]   → 最终版
```

### 4.2 产品设计流水线

```
[用户研究员] → 用户画像 + 痛点清单
    ↓
[产品经理]   → PRD 需求文档
    ↓
[UI设计师]   → 界面方案描述（用于AI生成设计稿）
    ↓
[技术评估]   → 可行性分析 + 技术选型建议
```

### 4.3 教学内容流水线

```
[课程设计师] → 教学目标 + 知识点大纲
    ↓
[内容创作者] → 逐课讲义 + 例题
    ↓
[练习设计师] → 课后作业 + 评分标准
    ↓
[讲师助手]   → 课堂讲义 + 常见问题预答
```

## 五、什么时候用原生联动，什么时候上平台

| 场景 | 原生 Prompt 联动 | OpenClaw/Coze/Dify |
|------|------------------|-------------------|
| 串行流水线（A→B→C） | ✅ 最适合 | 可以但没必要 |
| 输出是文档/代码/图片 | ✅ 复制粘贴就行 | 有版本管理更好 |
| 团队内自己跑流程 | ✅ 零学习成本 | ⚠️ 要搭建和配置 |
| 多角色并行处理同一问题 | ❌ 难协调 | ✅ Agent 对话 |
| 需要审批/权限/人工确认 | ❌ 手动 | ✅ 内置流程 |
| 长期运行/定时触发 | ❌ 需要人操作 | ✅ 自动化 |
| 多用户共享技能/记忆 | ❌ 无法共享 | ✅ 统一管理 |

**核心判断线**：如果任务是一个**线性流水线**且输出是**文档类产品**，原生联动就够；如果需要**多角色交互决策、自动化、多人共享**，再上平台。

## 六、从原生联动到平台化的演进

当你把原生流水线跑熟后，可以这样用平台提效：

1. **把每个角色指令转为 Skill**：编剧→写作Skill，分镜师→分镜Skill，角色设计→角色建模Skill
2. **接入工具**：分镜Skill自动调用即梦API生成参考图
3. **加入记忆**：角色设定存入记忆，下个短剧直接复用
4. **加入审批节点**：分镜输出后暂停，人工确认再进入视频生成
5. **串联成自动化流水线**：一个触发，全流程自动跑完

这就是从"手工作坊"到"自动化工厂"的演进——理解原生，才能用好平台。

## 七、练习

1. **搭你自己的第一个流水线**：选一个你日常需要做的事（写报告/做方案/写文章），拆成3个角色，写三个角色的提示词，跑一遍
2. **检查输入-输出对齐**：跑完后检查——角色三的输入是否严格引用角色二的输出？有没有凭空添加的信息？
3. **对比单Prompt vs 流水线**：把同一个任务用一个大Prompt一次性完成，再拆成流水线完成，对比效果和质量。记录你的发现
4. **进阶**：给你的流水线加一个"质检角色"——在所有角色输出后，加一个审校/验收角色，只负责检查上游输出的完整性和一致性
