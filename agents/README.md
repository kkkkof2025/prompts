# Agent 协作记录

本目录记录本项目中 AI agent 协作的约定、边界和本次任务轨迹，目的是让后续维护者知道哪些内容由并行 agent 协助生成，哪些内容需要复核。

## 协作原则

- 主书稿在 `docs/`，实践模板在 `examples/`。
- 并行 agent 只能修改自己被分配的目录，避免互相覆盖。
- 每次重要写作或资料更新后，同步更新根目录 `MEMORY.md`。
- 所有前沿事实都要标注核验日期，并尽量引用官方文档、论文、标准组织或可信年度报告。
- agent 输出可以作为草稿，发布前仍需人工复核，尤其是安装命令、安全建议、模型能力和价格相关内容。

## 本次 agent 分工

- 主线程：项目结构、README、MEMORY、`docs/` 书稿主体、资源引用。
- 并行写作 agent：`examples/` 下的 prompt、skill、agent 工作流模板。

## 后续可用 agent 任务

- 资料核验 agent：每季度检查 `docs/appendix-resources.md` 中链接和日期。
- 案例扩写 agent：为每章补充一个真实职业场景案例。
- 教学检查 agent：从初学者视角检查术语是否过密、示例是否可执行。
- 安全审查 agent：检查 agent、OpenClaw、MCP、文件操作、联网访问相关章节是否过度乐观。
