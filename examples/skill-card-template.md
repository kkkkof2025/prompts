# AI Skill/Card 可复用模板

Skill/Card 是一张“任务说明卡”。它把某类 AI 协作任务的用途、输入、输出、边界和验收标准写清楚，让同一个任务可以被稳定复用，也方便多人协作时对齐预期。

适合用于：

- 反复执行的任务，例如资料摘要、代码评审、学习计划生成。
- 需要控制输出质量的任务，例如报告初稿、课程练习、项目复盘。
- 需要交给不同人或不同 AI 工具执行的任务。

不适合用于：

- 目标还没有想清楚的探索性闲聊。
- 必须依赖实时事实但没有提供来源的判断。
- 高风险决策的最终裁定，例如医疗、法律、投资结论。

## 使用方式

1. 复制“空白模板”。
2. 用具体任务替换方括号内容。
3. 先用一个小样本测试。
4. 根据输出问题调整输入、边界和验收标准。
5. 稳定后再用于批量任务。

## 空白模板

```markdown
# Skill/Card 名称

## 一句话用途

【用一句话说明这个 Skill/Card 解决什么问题。】

## 适用场景

- 【场景 1】
- 【场景 2】
- 【场景 3】

## 不适用场景

- 【边界 1】
- 【边界 2】
- 【边界 3】

## 输入

必须提供：

- 【输入 1】：【说明格式、范围或要求】
- 【输入 2】：【说明格式、范围或要求】
- 【输入 3】：【说明格式、范围或要求】

可选提供：

- 【可选输入 1】：【说明何时需要】
- 【可选输入 2】：【说明何时需要】

输入示例：

【给一个最小可用示例】

## 输出

请输出：

1. 【输出项 1】
2. 【输出项 2】
3. 【输出项 3】

输出格式：

【Markdown 表格 / 分级标题 / JSON / 清单 / 邮件等】

## 工作规则

- 优先使用用户提供的资料。
- 不要编造来源、数据、经历或结论。
- 对不确定信息要标注“无法确认”。
- 如果输入不足，先提出最多【数量】个关键澄清问题。
- 保持语言风格：【简洁 / 教学式 / 专业 / 口语化】。

## 边界

可以做：

- 【允许的任务 1】
- 【允许的任务 2】
- 【允许的任务 3】

不可以做：

- 【禁止的任务 1】
- 【禁止的任务 2】
- 【禁止的任务 3】

需要人工确认：

- 【人工确认点 1】
- 【人工确认点 2】
- 【人工确认点 3】

## 验收标准

合格输出必须满足：

- 【标准 1】：【如何判断满足】
- 【标准 2】：【如何判断满足】
- 【标准 3】：【如何判断满足】
- 【标准 4】：【如何判断满足】

失败信号：

- 【常见失败 1】
- 【常见失败 2】
- 【常见失败 3】

## 自检清单

输出前检查：

- [ ] 是否完成所有必需输出项
- [ ] 是否遵守输出格式
- [ ] 是否标注不确定信息
- [ ] 是否避免编造事实
- [ ] 是否列出需要人工确认的内容
```

## 字段说明

| 字段 | 用途 | 初学者常见问题 |
| --- | --- | --- |
| 一句话用途 | 让执行者快速理解任务目标 | 写成“帮我优化内容”，过于模糊 |
| 适用场景 | 说明什么时候可以使用 | 把所有任务都塞进一张卡 |
| 不适用场景 | 防止 AI 误用 | 不写边界，导致输出越界 |
| 输入 | 明确需要哪些材料 | 只给目标，不给上下文 |
| 输出 | 规定交付物形态 | 没有字段要求，结果难复用 |
| 工作规则 | 约束 AI 的行为 | 忘记要求标注不确定信息 |
| 边界 | 说明能做和不能做 | 把建议误当最终决策 |
| 验收标准 | 判断结果是否合格 | 标准不可观察，例如“写得好” |
| 自检清单 | 输出前做最后检查 | 没有检查格式、事实和遗漏 |

## 示例：资料摘要 Skill/Card

```markdown
# 资料摘要 Skill/Card

## 一句话用途

把一段学习资料整理成适合初学者复习的结构化摘要。

## 适用场景

- 整理课程笔记。
- 总结文章、讲座或视频字幕。
- 为后续写作或复习建立素材卡片。

## 不适用场景

- 资料没有提供，但要求总结具体事实。
- 需要判断资料是否真实可靠。
- 需要生成正式引用格式但没有来源信息。

## 输入

必须提供：

- 原始资料：文章、笔记、字幕或摘录。
- 目标读者：例如零基础学习者、教师、产品经理。
- 摘要长度：例如 300 字、800 字或 5 个要点。

可选提供：

- 关注重点：例如概念、方法、案例、争议。
- 输出格式：例如表格、清单、问答卡。

## 输出

请输出：

1. 一句话概括
2. 核心要点，最多 5 条
3. 关键概念解释
4. 可以实践的行动建议
5. 资料中没有说明或无法确认的内容

输出格式：

使用 Markdown 分级标题和项目符号。

## 工作规则

- 只基于用户提供的资料总结。
- 不补充资料中没有出现的事实。
- 如果资料太短或上下文不足，先说明限制。
- 语言要适合初学者。

## 边界

可以做：

- 压缩信息。
- 提炼结构。
- 改写成更易懂的表达。

不可以做：

- 编造作者没有提到的观点。
- 把不确定内容写成确定结论。
- 替用户判断资料的真实性。

需要人工确认：

- 资料来源是否可靠。
- 摘要是否保留了原文重点。
- 是否可以公开使用原始资料。

## 验收标准

合格输出必须满足：

- 准确：不改变原资料核心意思。
- 简洁：没有明显重复和空话。
- 可复习：要点清楚，方便二次阅读。
- 有边界：标注资料中无法确认的内容。

## 自检清单

- [ ] 是否只使用了提供的资料
- [ ] 是否输出了所有指定部分
- [ ] 是否解释了关键概念
- [ ] 是否标注了不确定信息
- [ ] 是否适合目标读者
```

## 设计一个好 Skill/Card 的检查问题

- 这个任务是否会重复出现？
- 输入是否足够明确？
- 输出能否被别人直接使用？
- 边界是否能阻止 AI 编造或越权？
- 验收标准是否能被人工检查？
- 如果结果失败，能否看出是输入问题、规则问题还是格式问题？
