# Prompt 模板库

> 以下是可以直接复制使用的 prompt 模板。每个模板都经过测试验证。替换 `{大括号}` 里面的内容即可使用。

## 工作类

### 周报生成

```text
# 周报生成
日期：{YYYY-MM-DD} 至 {YYYY-MM-DD}

本周输入：
今日工作：{今天完成的工作，逐条列出}
进行中：{正在进行的工作}
问题与风险：{遇到的问题}

输出格式：
1. 本周摘要（50字以内）
2. 重点项目进展（表格：项目名|本周完成|下周计划|风险）
3. 关键数据（如有）
4. 需要的支持
```

### 会议纪要

```text
# 会议纪要生成
会议主题：{主题}
日期：{日期}
参会人：{名单}

会议录音/记录：
{粘贴会议记录}

输出格式：
1. 会议核心结论（3条，每条不超过30字）
2. 决议事项（表格：决议|负责人|截止日期）
3. 待讨论事项（表格：待讨论|提出人|建议讨论时间）
4. 下次会议建议议题
```

### 邮件草稿

```text
# 邮件生成
收件人：{角色/职位}
主题：{邮件主题}
我需要传达的信息：{核心信息}
语气：{正式/友好/紧急}

输出：完整的邮件正文，100-200字。
```

## 写作类

### 文章大纲

```text
# 文章大纲生成
主题：{文章主题}
目标读者：{读者描述}（如：零基础的AI初学者）
文章长度：{字数} 字
目标：读者读完能{收获什么}

输出：
1. 标题（3个候选）
2. 引言（50字概述，用什么钩子吸引读者）
3. 正文大纲（3-5个部分，每个部分的小标题和要点）
4. 结论（总结 + 行动建议）
```

### 内容润色

```text
# 内容润色
原文：
{粘贴原文}

要求：
- {改进方向，如：更简洁 / 更有说服力 / 更适合社交媒体}
- 保留核心信息不变
- 给出一版润色后 + 3条修改说明
```

### 翻译优化

```text
# 翻译
原文：{粘贴原文}
源语言：{语言}，目标语言：{语言}
风格：{直译/意译/本地化}
领域：{如：技术/商务/文学}

输出：翻译结果 + 3个关键翻译决策说明
```

## 学习类

### 概念解释

```text
# 概念解释
概念：{概念名称}
我的背景：{你的知识水平，如：完全零基础/有编程基础但不熟AI}

要求：
1. 用一句话概括
2. 用一个生活中的比喻解释
3. 举一个实际应用例子
4. 列出最容易误解的2个点
```

### 错题分析

```text
# 错题分析
我做的题目：{题目描述}
我的答案：{你的答案}
正确答案：{正确答案}

请分析：
1. 我错在哪里（核心误解是什么）
2. 正确的思路应该是什么
3. 防止下次再错的记忆方法
```

### 学习笔记整理

```text
# 学习笔记整理
我学的内容（录音/草稿）：
{粘贴你的学习记录}

输出：
1. 3个核心概念（每个一句话解释）
2. 概念关系图（用文字描述）
3. 3个自测题（覆盖核心概念）
```

## 代码类

### 代码审查

```text
# 代码审查
```{语言}
{粘贴代码}
```

检查项：
- 逻辑错误
- 安全问题
- 性能问题
- 命名和可读性
- 边界条件处理

输出：每个问题单独列出，标注严重度（高/中/低）+ 修复建议。
```

### Bug 排查

```text
# Bug 排查
问题描述：{发生了什么}
期望行为：{应该发生什么}
错误信息：{粘贴错误日志}
相关代码：
```{语言}
{粘贴相关代码}
```
已尝试的排查：{你已经试过的方法}

请按可能性从高到低列出3个可能原因，并给出排查步骤。
```

### 测试用例生成

```text
# 测试用例生成
函数/模块：{描述功能}
输入参数：{参数列表和类型}
期望输出：{期望行为}
边界条件：{你知道的边界情况}

输出：10条测试用例，包含正常的、边界的、异常的输入。
表格格式：输入|期望输出|覆盖场景
```

## 分析类

### 数据分析

```text
# 数据分析
数据：
{粘贴数据（CSV/表格/文字描述）}

分析要求：
1. 关键数据摘要（3-5条）
2. 异常数据点识别
3. 趋势判断
4. 3条可执行的建议
```

### 竞品分析

```text
# 竞品分析
产品：{你的产品}
竞品：{竞品名称，2-3个}

分析维度：
- 功能对比（表格）
- 优势/劣势分析
- 定价策略
- 用户评价关键点

输出：分析报告 + 3个可执行的产品建议
```

### 决策辅助

```text
# 决策辅助分析
决策问题：{描述你需要做的决定}
选项：
A: {选项A描述，含利弊}
B: {选项B描述，含利弊}
（可选更多选项）

评估维度：{如：成本、时间、风险、收益}

输出：
1. 每个选项在各维度的评分（1-5）
2. 综合建议
3. 选择某选项后需要注意的3个风险
```

---

## 使用说明

1. **复制模板** → 粘贴到 AI 对话框
2. **替换 `{变量}`** → 填入你的具体内容
3. **运行** → 查看结果
4. **不满意就追问** → "请把第2部分改得更详细"

**保存你常用的模板**：把改好的 prompt 存到 `prompts/` 文件夹，标注使用场景和效果。
